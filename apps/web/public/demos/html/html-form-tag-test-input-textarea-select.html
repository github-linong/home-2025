  • accept, 规定文件上传控件中期望的文件类型

隐藏域

  • autocomplete、list, 表单的自动填充功能
  • autofocus, 页面加载时自动聚焦到此表单控件
  • disabled, 表单控件是否被禁用
  • readonly, 控件的值不可编辑
  • required, 表示为必填项，提交表单前必须先检查该值
  • name, 提交的key
