Swagger / OpenAPI → TypeScript API Client

把 Swagger 2.0 / OpenAPI 3.x 规范（JSON / YAML）在线转换成 TypeScript 接口 + 请求函数。自研生成器纯前端零依赖，支持「文件树」输出。swagger-typescript-api 也支持 modular 文件树。含双引擎规范校验（结构检查 + Redocly lint）。

客户端：
输出形式：
「文件树」会把所有类型放进 types.d.ts，按 tag 拆分接口文件（如 pets.ts），并生成 http.ts 与 index.ts 入口；「单文件」则把所有内容合并进一个 .ts。
该生成器通过 https://esm.sh 动态加载，需要联网。若加载失败，会给出本地 Node 命令。
枚举风格：
openapi-typescript 默认输出 type Status = "a" | "b"，也可选 enum Status { ... }。
插件：
@hey-api/openapi-ts 通过插件扩展：类型 + 客户端必选，zod 生成校验 schema，react-query/solid-query 生成 hooks。
客户端：
Orval 的 output 配置决定生成客户端代码还是 hooks。
插件：
Kubb 插件架构：types 生成类型，zod 生成校验 schema，msw 生成 mock handler，faker 生成假数据。
客户端：
openapi-typescript-codegen 支持 fetch / axios / xhr / node-fetch 四种 HTTP 客户端生成。
输出形式：
swagger-typescript-api 的 modular 模式会按模块拆分 .ts 文件，并生成 data-contracts.ts（类型）、http-client.ts、Route.ts 等。

用到的开源项目（GitHub）

  • acacode/swagger-typescript-api 经典 生成带 axios/fetch 请求方法的完整 API Client。
  • openapi-typescript 零依赖 仅生成 .d.ts 类型，runtime-free，浏览器内也能跑。
  • @hey-api/openapi-ts 现代全功能客户端，插件化（zod / React Query）。
  • orval 客户端 + React Query / Vue Query hooks + mock + zod + MCP。
  • openapi-ui/openapi-ts-request 国产，Swagger2/OpenAPI3/Apifox → TS，含枚举翻译与 mock。
  • ferdikoomen/openapi-typescript-codegen 经典轻量，纯 Node.js，支持 Fetch / Axios / XHR，已归档。

说明：本页「自研生成器」是演示用的轻量实现（覆盖常见 path/query/body/enum/array/嵌套），并非生产级；生产项目建议直接用上面任一成熟工具（支持 YAML、引用拆分、自定义模板等）。
