### 解答思路
左侧目录树用 Element UI 的 `el-tree` 即可，如果数据量大需要关注虚拟化支持；右侧文件列表用常规的 Row/Col 布局组件就能实现；如果需要拖拽排序/移动文件，`Sortable.js`（及其对应的 Vue 封装）是常见选择。

### 详细说明
- **目录树**：使用 `el-tree` 组件展示树状目录结构。较新版本的 `el-tree` 已经支持虚拟化渲染，能较好地应对大量目录节点的场景；如果所用版本不支持虚拟化，或者性能仍不满足要求，可以更换为其他支持虚拟滚动的 tree 组件。
- **右侧文件列表**：不需要特别复杂的组件，普通的 `Row`、`Col`（网格布局）配合文件卡片/图标即可完成基础的文件列表展示布局。
- **拖拽功能**：如果需要实现拖拽移动/排序文件，可以直接引入 [Sortable.js](https://github.com/SortableJS/Sortable)，它在业界应用广泛，且据了解也已经支持配合虚拟化列表使用，能兼顾大数据量下的拖拽性能。

### 小结
Vue 2 实现文件管理器类功能，推荐组合：`el-tree`（支持虚拟化）做目录树、`Row/Col` 做右侧列表布局、`Sortable.js` 做拖拽交互，三者组合基本能覆盖文件管理器的核心交互需求，同时兼顾大数据量下的渲染和交互性能。
