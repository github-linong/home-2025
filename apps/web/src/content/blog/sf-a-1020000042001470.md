### 解答思路
浏览器默认的拖拽预览图是对被拖拽元素做的一次「快照截图」，通常只保留矩形边界，不会完整还原所有 CSS 效果（如圆角、阴影等）。要自定义拖拽时显示的图像，需要在 `dragstart` 事件里手动调用 `DataTransfer.setDragImage()`，传入自己想展示的图片/元素。

### 示例代码
```js
function dragstart_handler(ev) {
  const img = new Image();
  img.src = 'example.jpg';
  // 注意：width/height 在这里设置通常不会生效
  img.width = 50;
  img.height = 50;

  ev.dataTransfer.setDragImage(img, 0, 0);
}

element.addEventListener('dragstart', dragstart_handler);
```

### 详细说明
- `setDragImage(image, xOffset, yOffset)` 可以传入 `<img>`、`<canvas>` 甚至是任意 DOM 元素作为拖拽时跟随鼠标显示的图像，`xOffset`/`yOffset` 用来指定鼠标相对该图像的锚点位置。
- 如果想要圆角效果保留，最直接的方式是提前准备好一张已经带圆角效果的图片（比如用 `canvas` 提前把元素绘制成带圆角蒙版的图片），再传给 `setDragImage`，而不是依赖浏览器对原始 DOM 元素做自动截图。
- 也可以传入一个隐藏的、样式与原元素一致（包括圆角）的克隆 DOM 节点作为拖拽图像，效果会比图片更灵活。

### 小结
浏览器默认生成的拖拽预览图不会完整保留 `border-radius` 等样式，需要在 `dragstart` 事件中通过 `setDragImage` 手动指定一张自定义的（已经处理好圆角效果的）图像或元素来解决。
