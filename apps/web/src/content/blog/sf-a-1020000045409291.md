### 解答思路
把 JSON 当作树状结构，用先序遍历依次访问所有叶子节点，并用一个固定容量为 200 的队列保存结果：每当叶子节点数量超过 200，就把最早进入队列的节点移除（先进先出），遍历结束后队列里剩下的就是最后 200 个叶子节点。

### 示例代码（如有代码）
```js
function lastNLeaves(root, n = 200) {
  const queue = [];

  function traverse(node) {
    const children = node.children || [];
    if (children.length === 0) {
      queue.push(node);
      if (queue.length > n) queue.shift(); // 超出容量，移除最早的节点
      return;
    }
    for (const child of children) {
      traverse(child);
    }
  }

  traverse(root);
  return queue;
}
```

### 详细说明
- **先序遍历**：按照「根 → 子节点」的顺序递归访问树，保证叶子节点被访问到的顺序与其在树结构中的先后顺序一致。
- **判断叶子节点**：没有 `children`（或 `children` 为空数组）的节点即为末级子节点。
- **固定容量队列**：用数组模拟队列，每访问到一个叶子节点就入队（`push`），一旦长度超过 200，就移除队首元素（`shift`），这样队列始终维持最近访问到的 200 个叶子节点，遍历结束后即为所需结果。
- 如果树的规模很大，用 `shift()` 频繁移除队首元素会有一定的性能开销（数组整体前移），可以考虑用双端队列或环形缓冲区（ring buffer）进行性能优化，但对于常规数据规模，这种写法已经足够简单直观。

### 小结
思路的核心是先序遍历树 + 固定容量的先进先出队列：用队列自然地维护「最近 N 个」的语义，遍历完成后队列内容即为所需的最后 200 个叶子节点，实现简单且易于理解。
