### 解答思路

`el-table` 的 `select` 事件在单击某一行的选择框时触发，回调会同时提供「当前所有已选中的行」和「本次被点击的那一行」，通过判断这一行是否还存在于当前选中列表中，就能区分是勾选还是取消勾选。

### 示例代码

```html
<el-table
  ref="multipleTable"
  :data="tableData"
  tooltip-effect="dark"
  style="width: 100%"
  @select="handleSelect">
</el-table>
```

```js
handleSelect(selection, row) {
  const isSelected = selection.includes(row);
  console.log('handleSelect', selection, isSelected);
  // isSelected 为 false 时，row 就是被取消勾选的那一行
}
```

### 详细说明

`el-table` 的 `select` 事件回调参数含义是：

- 第一个参数（`selection`）：触发事件后，表格当前**所有已勾选**的行组成的数组。
- 第二个参数（`row`）：本次**被单击操作**（勾选或取消勾选）的那一行数据。

因此只需要判断 `selection.includes(row)`：如果结果为 `true`，说明这一行刚被勾选进 `selection`；如果为 `false`，说明这一行虽然被点击了，但已经不在 `selection` 里了，也就是刚被取消勾选。

### 小结

利用 `el-table` 的 `select` 事件回调中「已选列表」与「本次操作行」两个参数做一次 `includes` 判断，即可准确识别出用户是勾选还是取消勾选了某一行。
