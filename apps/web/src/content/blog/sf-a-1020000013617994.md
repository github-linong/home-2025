### 解答思路
问题的根源在于路由模式和参数获取方式不匹配：如果项目使用的是 hash 模式路由（`#` 开头），实际参数是拼接在 `location.hash` 里的，而提问者却用 `location.search` 去获取，自然拿不到值，一直是 `null`。

### 详细说明
- Vue Router 默认（或常见配置）使用 hash 模式，URL 形如 `http://example.com/#/page?id=1`，此时 `?id=1` 是 `hash` 部分（`#/page?id=1`）的一部分，`location.search` 拿到的只是 `#` 前面的查询字符串（大多数情况下是空的），所以取不到参数。
- 正确的做法是从 `location.hash` 中解析出 `?` 之后的部分，或者在 Vue 组件里直接使用 `this.$route.query`（对应 `?xxx=xxx` 的参数）或 `this.$route.params`（对应路由路径中的动态段），由 Vue Router 帮你处理好 hash/history 模式的差异，而不必手动解析 `location`。

### 小结
在 hash 模式的路由下，URL 参数藏在 `location.hash` 而不是 `location.search` 里；在 Vue 项目中更推荐直接使用 `this.$route.query` / `this.$route.params` 获取参数，避免手动解析带来的模式混淆问题。
