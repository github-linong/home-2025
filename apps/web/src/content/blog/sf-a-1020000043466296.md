### 解答思路
浮动元素的宽度、高度属于会影响布局的几何属性，修改后会触发重排（Layout），这个结论可以通过实际测试代码验证。

### 示例代码（如有代码）
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <title>Document</title>
  <style>
    .box .float {
      float: left;
      width: 80px;
      height: 100px;
    }
    .box .float[data-width="1"] { width: 180px; }
    .box .float[data-width="2"] { width: 280px; }
    .box .float[data-width="3"] { width: 380px; }
    .box .float[data-height="1"] { height: 180px; }
    .box .float[data-height="2"] { height: 280px; }
    .box .float[data-height="3"] { height: 380px; }
  </style>
</head>
<body>
  <div class="box">
    <img id="img" src="https://cdns.jsrun.net/css/img/logo@2x.png" alt="" class="float" />
    <!-- ...周围文字内容... -->
  </div>
  <script>
    setInterval(() => {
      img.dataset.height = (Number(img.dataset.height || 0) + 1) % 3;
    }, 1000 * 3);
  </script>
</body>
</html>
```

验证要点：定时修改 `img` 元素的 `data-height`，从而切换宽高对应的 CSS 属性，观察周围内容是否重新排布。

### 详细说明
- 从图层（Layer）角度看，测试中的浮动元素与周围内容处于同一图层；从渲染流程（Rendering）看，`paint` 对应「重绘」，`layout` 对应「重排」。
- 实测发现：给浮动元素加上 `position: absolute` 之后，修改宽高不再触发 `layout`，说明浮动元素脱离常规流参与布局计算，而绝对定位元素的宽高变化不会影响其他元素排布，因此不会触发整体重排。
- 想查询某个 CSS 属性具体会触发「重排 / 重绘 / 复合层」中的哪一种，可以使用 [CSSTriggers](https://csstriggers.com/) 这个网站进行对照查询，它按属性名称列出了对应的渲染影响。

### 小结
`float` 元素修改宽高会触发重排（Layout），因为它仍参与常规文档流的布局计算；而改为 `position: absolute` 后，宽高变化只影响自身，不再触发外部重排。日常排查渲染性能问题时，可以借助 CSSTriggers 快速判断某个属性的渲染影响类型。
