### 解答思路
`Array.prototype.sort()` 在**不传比较函数**时，会先把元素转换成字符串，再按字符（字典序/Unicode 码点）进行比较排序，这恰好等价于“按首位数字排序”。

### 示例代码
```js
const arr = [12, 3, 24, 1, 932, 6423];
console.log(arr.sort());
// [1, 12, 24, 3, 6423, 932]
```

### 详细说明
- 默认 `sort()` 会把每个数字转成字符串再比较，例如 `'932'` 和 `'12'` 比较时，先比较首字符 `'9'` 和 `'1'`，`'1'` 更小，所以 `12` 排在 `932` 前面，这正好符合“按首位”排序的直觉。
- 需要注意：这是 `sort()` 的默认行为，如果目的是数值大小排序，必须显式传入比较函数 `arr.sort((a, b) => a - b)`，否则会得到本例这种按字符串比较的结果。

### 小结
恰好利用了 `sort()` 不传参数时按字符串比较的默认行为，实现了“按首位数字排序”的效果；但要清楚这是默认行为的副作用，不要与数值排序混淆。
