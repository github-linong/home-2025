### 解答思路
JavaScript 引擎在代码执行前会先做语法/词法分析，此时会把变量声明和函数声明“提升”到作用域顶部；函数声明（`function fn(){}`）会连同函数体一起提升，而函数表达式（`var fn = function(){}`）只会提升变量名 `fn`，赋值部分不会提升。

### 示例代码
```js
var func;
console.log(func); // undefined

if (true) {
  func = function () {
    console.log('11');
  };
} else {
  func = function () {
    console.log('22');
  };
}

func(); // 11
```

### 详细说明
- `if` 只是条件判断语句，浏览器在编译阶段只做语法检查，不会提前执行分支逻辑。
- 变量提升规律是“函数优先”：`var a = 1; function fn(){}` 这类代码里，`var a;` 和 `function fn(){}` 都会被提升到作用域顶层，且函数声明的提升优先级高于同名的 `var` 变量声明。
- 函数表达式（`var fn = function(){}`）只提升 `var fn;` 这一行，赋值语句仍在原来的位置执行，因此在赋值之前调用会得到 `undefined` 而不是函数体。
- 在 `if/else` 块内声明函数（非表达式形式）的提升行为，不同浏览器、是否开启严格模式下表现可能不一致，建议实际测试或改用函数表达式规避歧义。

### 小结
函数声明会整体提升（包括函数体），函数表达式只提升变量名；在条件块内使用函数声明容易出现浏览器兼容性问题，实践中更推荐使用函数表达式并提前用 `var` 声明变量以获得确定的行为。
