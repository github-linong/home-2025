### 解答思路
用 `reduce` 遍历原数组，累积一个去重后的结果数组：对每一项先用 `findIndex` 检查结果数组里是否已经存在同名的记录——不存在就直接加入；存在则比较 `created_at`，当前项时间更早就用它替换已存在的记录。

### 示例代码
```js
const list = [
  { name: '玉骨遥寒薇结海报', created_at: '2021-06-04 04:54:06.164' },
  { name: '玉骨遥寒薇结海报', created_at: '2021-06-04 04:52:49.753' },
  { name: '玉骨遥寒薇结海报', created_at: '2021-06-04 05:02:02.398' },
  { name: '公交车抛锚警民携手推车为考生开路', created_at: '2021-06-04 04:52:40.588' },
  { name: '公交车抛锚警民携手推车为考生开路', created_at: '2021-06-04 05:07:21.587' },
];

const result = list.reduce((acc, cur) => {
  const idx = acc.findIndex((item) => item.name === cur.name);
  if (idx === -1) {
    acc.push(cur);
  } else {
    const existing = acc[idx];
    if (cur.created_at < existing.created_at) {
      acc.splice(idx, 1, cur);
    }
  }
  return acc;
}, []);

console.log(result);
```

### 详细说明
- `findIndex` 用来判断结果数组中是否已经有同名记录，时间复杂度是 O(n)，数据量大时可以考虑先用 `Map` 按 `name` 建立索引来优化到 O(1) 查找。
- 时间字符串比较（`cur.created_at < existing.created_at`）能生效的前提是时间格式可以按字典序比较（如 `YYYY-MM-DD HH:mm:ss.SSS`），本例格式满足这个条件。
- 数据量较大时更推荐使用 `Map` 优化版本：

```js
const map = new Map();
for (const item of list) {
  const existing = map.get(item.name);
  if (!existing || item.created_at < existing.created_at) {
    map.set(item.name, item);
  }
}
const result2 = [...map.values()];
```

### 小结
小数据量用 `reduce` + `findIndex` 即可简洁实现按字段去重并保留特定记录；数据量较大时建议改用 `Map` 索引来提升查找效率。
