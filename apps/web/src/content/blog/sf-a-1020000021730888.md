### 解答思路

针对封面图裁剪问题，提供了三种递进的方案：优先用 CDN 的裁图能力在图片源头处理；如果已经改用 `<img>` 标签展示封面，可以考虑用 `background-image` 承载；或者直接给 `<img>` 使用 CSS 的 `object-fit` 属性来控制裁剪填充规则。

### 详细说明

1. **不改动程序结构，直接用 CDN 裁图**：很多图片 CDN 支持通过 URL 参数动态裁剪、缩放图片，无需修改前端代码即可让封面图按需展示，改动成本最低。
2. **用 background-image 替代 img 标签**：如果已经用 `<img>` 展示了封面，那么用 `background-image` 配合 `background-size: cover` 等属性同样可以灵活控制裁剪规则，效果与方案 1 类似。
3. **用 CSS object-fit 控制 img 的裁剪方式**：即使继续使用 `<img>` 标签，也可以通过 [`object-fit`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/object-fit)（如 `object-fit: cover`）来控制图片在固定容器内的填充/裁剪方式，无需切换到背景图方案。

三种方案可以根据现有代码结构和改动成本灵活选择，效果上是等价的。

### 小结

处理视频封面图的裁剪显示问题，可以优先用 CDN 裁图能力从源头解决；若需要在前端控制，`background-image` 与 `<img>` 的 `object-fit` 属性都能实现类似 `cover`/`contain` 的裁剪填充效果。
