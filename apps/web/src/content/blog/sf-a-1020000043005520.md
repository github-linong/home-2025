### 解答思路
用正则 `/[^a-z]/i` 匹配所有「非字母」字符作为分隔符对字符串进行切割，得到一个单词数组，再用 `Set` 去重；需要注意如果原字符串以非字母字符开头/结尾，或包含连续的非字母字符，`split` 结果里会出现空字符串，需要额外过滤。

### 示例代码
```js
const str = 'Hello, world! Hello world.';

const words = new Set(str.split(/[^a-z]/i));
console.log(words);
// 注意：其中可能包含一个空字符串 ''，因为标点符号被当作分隔符处理

// 更严谨的写法：过滤掉空字符串
const cleanWords = new Set(
  str.split(/[^a-z]/i).filter((w) => w.length > 0)
);
console.log(cleanWords);
```

### 详细说明
- `/[^a-z]/i`：`[^a-z]` 表示「不是小写字母 a-z 的任意字符」，加上 `i` 标志忽略大小写，所以实际匹配的是「非英文字母」的所有字符（空格、标点、数字等）。
- `split` 按这个正则切割字符串后，会把所有非字母的片段当作分隔符去掉，剩下的都是连续字母组成的“单词”。
- 由于文本中标点/空格经常连续出现（或出现在开头结尾），`split` 结果数组里几乎一定会混入空字符串 `''`；用 `Set` 去重时这个空字符串也会被当作一个（唯一的）成员保留下来，如果不想要，需要 `filter` 掉。

### 小结
用 `split(/[^a-z]/i)` 可以快速把文本切分成单词数组，再用 `Set` 去重；但要留意分割结果中混入的空字符串，视需求决定是否需要 `filter` 掉。
