### 解答思路
闪烁的根本原因是第二张图片在 hover 触发时才开始加载，加载耗时导致画面出现空白/延迟。解决方向就是让第二张图片**提前加载好**，而不是等到 hover 时才加载。

### 详细说明
常见的三种解决方式：

1. **CSS Sprite（雪碧图）**：把两张图拼接成一张图，通过 `background-position` 控制显示哪部分，避免加载第二张单独的图片。
2. **多背景图 + 提前设置**：`background` 支持同时设置多张图片，可以让两张图在页面加载时就一起请求，hover 时只是切换显示层级/坐标，不产生额外的网络请求。
3. **JS 预加载**：用 `Image` 对象提前把第二张图加载到浏览器缓存里，hover 时直接从缓存读取，不再有加载延迟。

### 示例代码
```css
.icon {
  width: 32px;
  height: 32px;
  background-image: url('sprite.png');
  background-position: 0 0;
}
.icon:hover {
  background-position: 0 -32px;
}
```

```js
const preload = new Image();
preload.src = 'hover.png';
```

### 小结
Hover 闪烁本质是“图片没提前加载好”，解决思路都是围绕「提前加载」展开：雪碧图、多背景图或 JS 预加载三选一即可。
