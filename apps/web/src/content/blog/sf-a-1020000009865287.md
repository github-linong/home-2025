### 解答思路
JavaScript 变量（以及某些场景下直接当作标识符使用的名称）命名规则中不允许使用连字符 `-`，把 `-` 换成下划线 `_` 即可解决报错，例如把 `add-button` 改成 `add_button`。

### 详细说明
JavaScript 标识符的命名规则是：只能以字母、下划线 `_` 或美元符号 `$` 开头，后面可以跟字母、数字、下划线或 `$`，但命名规则里**不包含连字符 `-`**。如果直接把带连字符的名字当作变量名使用（例如把 CSS 中常见的 `add-button` 直接拿来当 JS 变量名），会被解析成“变量 `add` 减去变量 `button`”，从而报错。解决办法很简单：把连字符换成下划线，写成 `add_button`，或者使用驼峰命名 `addButton`。

### 小结
CSS 类名可以用连字符，但 JavaScript 变量名不能，混用时把 `-` 替换为 `_`（下划线命名）或改用驼峰命名即可避免报错。
