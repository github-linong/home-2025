## 不知道你还记得第一次接触编程时的心情吗？

不知道你是否还记得，但是我一直记得，并且会一直记得。

我也有边城大佬的困惑「到底哪一份才算是第一份呢？」

### 第一次看到 Code

我最早见到的 Code 是在杂志《黑客 X 档案》 （github），不知道有看过的小伙伴吗。
当时应该是 2002-2005 年之间，家里的电脑还是 「win98」 系统（方方的显示器前面有一个磨砂护眼的挡板），游戏的话有可能会有一个盗版的「仙剑奇侠传98柔情版」。
那个时候《黑客 X 档案》会携带一个光盘，里面附带本期杂志的案例病毒和代码（会有那种如何破解网吧收费系统的案例，可惜没机会尝试），现在想想有可能是一些 `cmd` 的命令，执行 `.bat` 之类的东西，然后附带一些扫描、控制工具

### 第一次编写 Code

我认为这是我的第一次接触编程，那应该是 2011 年吧。
老师是刚毕业的杨老师，当时我正在课上睡觉（😪 信我，编程助眠），感谢杨老师把我叫醒并嘲讽我是不是不行。

那时讲的编程语言是 `**`（你猜是什么？），实现的功能应该是渲染一个按钮，点击执行++。
听起来功能是不是很简单？但是就是这样的一个功能，把我难住了。
当然故事的结局是我现实了这个功能，不然也不会有现在的我在这里写回忆录。实现的方法就是请教会的人🐶，所以不懂真的要问，不要怕丢人。
因为我迈过了第一次的门槛，所以我才有机会持续深入，当时的大部分同学现已不从事计算机相关行业。当你持续学习永不放弃，你会超越很多人。

### 第一次编写 Code 获利

我认为我通过编程有很长一段时间都只是获利，但是没有赚到钱。

因为当时大家都是穷学生嘛，无非就是我给你抄个大作业，你给我买个可乐、吃顿食堂。

我收获了自信，自信的人是真的在发光💡。其实这是一把双刃剑，在某些演变下会变成狂傲无知。

### 第一次编写 Code 赚钱失败

是的，你没看错，赚钱失败

项目是「CMS 企宣网」，当时是 2015 年 8 月，当时还有张前端同学（对不起对不起🧎‍），苏美工同学，李PHP同学（🐶）

项目初期觉得钱很好挣，项目中期发现客户真是折磨怪，项目后期发现我坑了张前端同学（虽然你很开朗，但是还是再次说对不起）。

这个项目耗时一个月，以分文不挣，自掏腰包结束。

## 这么多的第一次有什么经验吗？

「人类唯一能从历史中吸取的教训就是，人类从来都不会从历史中吸取教训」

我的经验总结，没有相同的环境，无法感同身受
- 自信很重要，我觉得我能在研发岗位混饭到现在，和从 11 年那次开始积累的自信心有很强的关联。
- 诚信很重要，虽然我们无法要求别人，但是我们可以要求自己，然后尽可能和诚信的人合作。
- 老板很重要，可惜我居然忘了（失了智，不过再一次选择的话，我会更早）。一个人的成长离不开环境，而一个环境的好坏，往往由你的老板决定。
- 说话要注意分寸、时机。讲真的，我这张破嘴，太得罪人了。笨也就算了，居然还能得罪人
- 持续学习

上述的每一个点，其实都可以对应到每一段经历中
