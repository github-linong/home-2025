### 解答思路

jQuery 中常见的「选中一组元素再遍历处理」的逻辑，原生 JS 可以用 `document.querySelectorAll` 配合 `Array.from` 转换为真正的数组后，再调用数组的 `forEach` 方法来实现。

### 示例代码

```js
// 选中所有匹配的元素（返回 NodeList，类数组对象）
const imgList = document.querySelectorAll('.entry-content p img, .lonesome-img a img');

// 转换成真正的数组，才能使用完整的数组方法
const imgArray = Array.from(imgList);

imgArray.forEach((img) => {
  // 对每个 img 元素进行处理
});
```

### 详细说明

- `document.querySelectorAll(selector)` 是原生 DOM API，功能上等价于 jQuery 的 `$(selector)`：可以用逗号分隔多个选择器（如 `.entry-content p img, .lonesome-img a img`），一次性选出所有匹配的元素。它返回的是一个 `NodeList`（静态的类数组对象），本身不具备数组的所有方法（比如没有 `.map`、`.filter` 等）。
- `Array.from(nodeList)` 可以把 `NodeList` 转换成一个真正的数组，之后就能使用数组原生的 `forEach`、`map`、`filter` 等方法，写法上和 jQuery 遍历元素后调用 `.each()` 的体验类似。
- 需要注意的是，如果项目里已经引入了 jQuery，其实没有必要为了「去 jQuery 化」而增加代码复杂度；只有在确实需要移除 jQuery 依赖、减少打包体积的场景下，才有必要用 `querySelectorAll + Array.from` 这类原生写法逐步替换。

### 小结

用原生 JS 替代 jQuery 的「选中元素并遍历」逻辑，核心组合是 `document.querySelectorAll` 负责选中元素、`Array.from` 负责转换为标准数组、`forEach` 负责遍历处理；是否要做这种替换，取决于项目是否真的需要摆脱 jQuery 依赖。
