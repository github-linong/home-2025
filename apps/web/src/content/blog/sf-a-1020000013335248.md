### 解答思路
使用 `document.querySelectorAll` 配合 CSS 子选择器 `>`，可以精确获取某个元素下的直接子元素。

### 示例代码
```js
document.querySelectorAll('#uu>li');
```

### 详细说明
`#uu>li` 是一个 CSS 子选择器，表示“id 为 `uu` 的元素下的直接子级 `li` 标签”，不会选中嵌套在更深层级（比如 `li` 内部又套了一层 `ul>li`）的元素。`querySelectorAll` 会返回一个 `NodeList`，包含所有匹配的 `li` 元素，可以用 `for` 循环或 `Array.from(...).forEach()` 进一步遍历处理。如果只需要第一个匹配项，可以改用 `querySelector`。

### 小结
获取某个 `ul` 下的所有 `li`，用 `document.querySelectorAll('#uu>li')` 即可；子选择器 `>` 能保证只取直接子元素，避免误选中嵌套结构里的同名标签。
