### 解答思路
这种现象通常是浏览器默认的文本选择行为被触发（比如快速点击、拖动式点击），可以通过 CSS 禁止该元素及其周边内容被选中来解决。

### 示例代码
```css
.no-select {
  user-select: none;
}
```

### 详细说明
给触发点击的元素（或其外层容器）加上 `user-select: none`，可以阻止用户在该区域内通过鼠标操作选中文本，从而避免点击时“顺带”选中旁边文字的问题。如果需要兼容旧版浏览器，可以补充 `-webkit-user-select`、`-moz-user-select`、`-ms-user-select` 等前缀属性。

### 小结
点击时误选中旁边文字，本质是浏览器默认的文本选择行为，加上 `user-select: none` 即可屏蔽该行为。
