## vscode

程序员的工作中编辑器是必不可少，我们应该将我们的编辑器变得酷一点，然后再来点快捷键让我们骚起来。

### 安装编辑器

https://code.visualstudio.com/ 下载安装包（我特意删了我的编辑器，从头来过，感动吗？）

下载之后无脑下一步（当然我是会改个路径的）。

### 插件管理
- 直接在侧边工具栏单击

- file（文件） > perferences（首选项） > extensions（扩展）

#### 插件安装&插件推荐
- 编辑器改为中文。插件关键词：Chinese 
（可以看到搜索联想推荐中就有）

选择 `Chinese (Simplified) Language Pack for Visual Studio Code` 插件 install（安装）

安装完成之后，右下角会提示重启生效。然后重启就 ok 了

- 美化代码 prettier。插件关键词：prettier 
有的时候我们会看到一些怪异的代码，但是一行一行改又太累了。

我们可以通过 `alt + shift + f` 来美化一下代码。（默认就携带的功能，但是功能感觉较弱）

我们可以装其他的美化插件，首次使用会提示你安装了多个格式化插件，选择我们新安装的即可。

- 
输入特效。插件关键词：Power Mode
需要修改一下配置

```
"powermode.enabled": true,
"powermode.presets": "fireworks",
"powermode.shakeIntensity": 0 
```

就可以看到特效了

### 常用快捷键（windows）
- `ctrl + D` 选中下一个相同的内容
`ctrl + shift + L` 选中所有相同的内容

比如要实现批量注释掉 `console.log`，`ctrl + shift + L` 然后 `ctrl + /`

- `ctrl + G` 跳转到指定行列
一般用于我们在控制台定位到了问题，然后去文件中修改时

### 修改快捷键

有可能我们习惯在很久之前就已经养成。那么我们会考虑修改一下默认快捷键
