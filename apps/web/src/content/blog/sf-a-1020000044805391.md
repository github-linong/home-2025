### 解答思路
浏览器本身无法直接读取用户的公网 IP，只能通过向服务器发起一次请求，由服务器读取请求的来源 IP 并返回给前端，从而间接获取出口 IP。

### 详细说明
- 前端在 Vue 组件中发起一个普通的 HTTP 请求（比如请求自己搭建的服务），服务端根据请求头（如 `X-Forwarded-For`、`req.socket.remoteAddress` 等）解析出客户端的出口 IP，再把结果返回给前端。
- 需要注意的是，这个方式获取到的是网络出口 IP（比如公司/家庭路由器对外的 IP），而不是用户本机在局域网内的真实内网 IP，浏览器出于安全限制，前端无法直接拿到用户机器的内网 IP。
- 实际项目中，这类功能一般由后端统一提供接口能力（获取 IP、地理位置等），前端调用即可，没有必要自己维护一套 IP 探测逻辑。

### 小结
Vue（前端）本身不具备读取用户 IP 的能力，常见做法是请求一个服务端接口，由后端解析请求来源 IP 并返回。这类基础能力通常应该由后端统一提供，前端只需调用即可。
