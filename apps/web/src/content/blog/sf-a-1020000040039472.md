### 解答思路
`<a href="...">` 发起的是浏览器原生请求，无法附加自定义请求头。如果后端要求必须通过请求头传递 token，就不能直接用 `<a>` 标签下载，而要先用 AJAX/`fetch` 携带请求头去请求资源，拿到二进制数据（`Blob`）后再触发下载。

### 示例代码
```js
async function downloadWithAuth(url, token, filename) {
  const res = await fetch(url, {
    headers: {
      Authorization: `Bearer ${token}`,
    },
  });
  const blob = await res.blob();

  const link = document.createElement('a');
  link.href = URL.createObjectURL(blob);
  link.download = filename;
  link.click();
  URL.revokeObjectURL(link.href);
}
```

### 详细说明
- 第一步：用 `fetch`（或 `axios`）发起请求，在 `headers` 里带上需要的 `Authorization`/token。
- 第二步：把响应体以 `blob` 类型接收，得到文件的二进制数据。
- 第三步：用 `URL.createObjectURL(blob)` 生成一个临时的本地 URL，赋给动态创建的 `<a>` 标签的 `href`，并设置 `download` 属性，再调用 `click()` 触发浏览器下载。
- 下载完成后建议调用 `URL.revokeObjectURL` 释放内存。

### 小结
原生 `<a>` 标签无法携带请求头，涉及鉴权的下载场景需要先用 AJAX 请求资源并转为 `Blob`，再用临时 `<a>` 标签触发下载。
