### 解答思路
遍历 `obj2` 自身的键，用同名键去 `obj1` 中取值，逐一赋值覆盖即可。

### 示例代码
```js
const obj1 = { a: 1, b: 2, c: 3, d: 4 };
const obj2 = { b: 0, c: 0 };

Object.keys(obj2).forEach((key) => {
  obj2[key] = obj1[key];
});

console.log(obj2); // { b: 2, c: 3 }
```

用 Lodash 也可以更简洁地实现类似效果：
```js
import _ from 'lodash';

const result = _.pick(obj1, Object.keys(obj2));
// result: { b: 2, c: 3 }
```

### 详细说明
- 关键是遍历顺序：以 `obj2` 的键为基准，而不是 `obj1`，这样才能保证只更新 `obj2` 已有的字段，其余字段（`obj1` 里的 `a`、`d`）不会被带进来。
- 如果不需要保留 `obj2` 原有引用，只是想拿到一个新对象，`lodash` 的 `_.pick(obj1, keys)` 会更直观：从 `obj1` 中挑出指定键组成新对象。

### 小结
按指定键做“选择性赋值”，核心思路是「以目标对象的键为遍历基准」，原生 `Object.keys().forEach()` 或 `lodash` 的 `pick` 都能实现。
