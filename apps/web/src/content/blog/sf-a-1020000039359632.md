### 解答思路
局部光照效果通常不是靠单一 CSS 属性直接实现，而是组合使用「遮罩层 + 鼠标位置计算 + 层级控制」：
1. 用一个覆盖全区域的半透明遮罩模拟“变暗”的背景；
2. 通过 JS 监听鼠标位置，动态调整光照容器的位置；
3. 如果只需要简单的聚光效果，也可以用 `box-shadow` 配合定位元素实现发光边界。

### 示例代码
```css
.light {
  position: absolute;
  width: 200px;
  height: 200px;
  border-radius: 50%;
  box-shadow: 0 0 60px 40px rgba(255, 255, 255, 0.8);
  pointer-events: none;
}
```

```js
document.addEventListener('mousemove', (e) => {
  light.style.left = `${e.clientX}px`;
  light.style.top = `${e.clientY}px`;
});
```

### 详细说明
- 若需求是「鼠标覆盖区域变亮、其余区域变暗」，注意 `box-shadow` 方案会连文字一起盖住；若不希望遮住文字，需要调整层级（`z-index`）把文字放在遮罩之上。
- 更精确的做法是用 JS 实时获取鼠标所在的容器区域，只对区域外的部分加半透明遮罩，区域内保持正常显示，避免遮住不该遮住的内容。

### 小结
纯 CSS 很难完美还原局部光照效果，通常需要结合 JS 动态计算鼠标位置和区域，再用 `box-shadow` 或遮罩层配合层级控制来实现。
