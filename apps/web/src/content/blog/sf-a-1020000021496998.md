### 解答思路

核心思路是：先算出圆上任意一点的坐标，再以固定弧度为步长遍历圆周上的多个点；每两个相邻点连成的线段方向，就是该处箭头应该旋转的角度。绘制时使用 `translate` 把画布原点移动到目标点，再用 `rotate` 旋转到计算出的角度，最后绘制箭头图形。

### 详细说明

- **确定圆上点的坐标**：给定圆心、半径和角度 θ，点坐标为 `(cx + r*cos(θ), cy + r*sin(θ))`。
- **以固定弧度为步长遍历**：从 0 到 2π，按固定步长（如 `Math.PI / 16`）遍历，得到圆周上一系列点。
- **计算箭头角度**：取相邻两点，用 `Math.atan2(dy, dx)` 计算出这两点连线的角度，即为箭头应旋转的角度（因为箭头要沿圆周的切线方向指向前进方向）。
- **绘制**：对每个点执行 `ctx.save()` → `ctx.translate(x, y)` → `ctx.rotate(angle)` → 绘制箭头 → `ctx.restore()`，这样每个箭头都会基于自己的位置和角度正确渲染。

可参考回答中提供的在线 Demo（http://jsrun.pro/tRWKp/edit）获取完整实现代码。

### 小结

用 `translate + rotate` 组合是 Canvas 中处理「沿路径分布并按切线方向旋转的图形」的通用技巧：先定位，再旋转，最后绘制，即可实现环形箭头一类的效果。
