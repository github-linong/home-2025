## 简介

DOM / HTML API 试验页：getAttributeNode、dispatchEvent 等接口的小实验集合。

## 如何测试验证

1. 按页面按钮触发各 API，在控制台观察返回值。
2. 手动修改属性后再读取，确认 Attr 节点行为。
3. dispatchEvent 自定义事件，确认监听器收到。
