## 简介

百度 AI 人脸融合 / 人脸相关能力的前端 Demo。流程与 Face++ 类似：选图 → 调 API → 展示结果，便于对比不同厂商参数差异。

## 如何测试验证

1. 上传符合要求的人脸图片（清晰、无遮挡）。
2. 提交请求，观察返回 JSON / 结果图。
3. 若 Access Token 过期，按百度开放平台文档重新获取。
4. 对比不同融合度参数对结果的影响。
