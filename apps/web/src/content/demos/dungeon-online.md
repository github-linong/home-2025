《余烬小队》浏览器试玩版：拉上好友组队，逐层深入随机生成的地牢。

- 2–4 人小队合作：协作技、救援机制与有限资源强制配合，「救不救队友」是反复出现的抉择
- 像素风 2D 俯视，逐层下行，每局布局 / 敌人 / 资源都有变化
- 轻量 Build 构筑：职业、技能、下行路线与资源分配构成局内决策纵深
- 权威服务器结算：伤害与状态全部在服务端裁定，客户端预测 + 回正，宽容网络抖动
- 断线即重连：掉线玩家角色由服务器保留，重连归队，战局不散
