## 简介

Chrome Sources / 断点调试相关演示：在页面中触发可调试脚本，配合 debugger、XHR、jQuery Ajax。

## 如何测试验证

1. 打开 DevTools → Sources，按文章步骤下断点。
2. 点击页面按钮命中断点。
3. 对比同步代码、XHR 回调、$.ajax 回调的调用栈。
