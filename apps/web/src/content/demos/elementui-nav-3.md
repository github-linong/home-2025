## 简介

Element UI 导航联动示例：菜单高亮与路由 / 内容区同步。适合后台布局实践。

## 如何测试验证

1. 点击侧边 / 顶部菜单，确认内容切换。
2. 刷新页面，确认激活项与路由一致（若有路由）。
3. 缩小窗口，检查折叠菜单行为。
