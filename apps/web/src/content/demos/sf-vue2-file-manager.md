## 简介

用 Vue 2 与 Element UI 搭的迷你「文件管理器」：左侧树浏览目录，右侧列出文件，一眼能看懂典型后台资源管理布局与选中/导航交互。适合当作 Element 树表组合的样例页。

## 如何测试验证

1. 展开/收起左侧树节点，确认选中态同步到右侧列表。
2. 点击不同目录，检查列表内容是否切换。
3. 打开开发者工具，确认页面未因缺 CDN（Vue / Element）报错。
