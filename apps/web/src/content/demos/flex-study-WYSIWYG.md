## 简介

Flexbox 所见即所得学习工具：通过控件调整 justify-content、align-items、flex-grow 等，实时观察布局变化。

## 如何测试验证

1. 切换主轴方向（row / column），观察子项排列。
2. 调整 justify / align，确认对齐符合预期。
3. 给子项设置不同 flex-grow / basis，验证空间分配。
4. 对照 DevTools Flex 调试面板结果是否一致。
