## 简介

用设备倾斜 / 加速度驱动页面内小球滚动，直观展示传感器数据到 UI 的映射。

## 如何测试验证

1. 真机打开后倾斜手机，观察小球方向是否跟随。
2. 调节灵敏度阈值，对比手感。
3. 锁屏或切后台再回来，确认监听是否正确移除 / 恢复。
