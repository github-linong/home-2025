## 简介

文件预览系列：演示 accept、capture、multiple 等 input 属性对选文件体验的影响（相机、多选、类型过滤）。

## 如何测试验证

1. 在手机上测试 capture=environment / user。
2. 设置 accept 仅图片，尝试选其他类型是否被拦。
3. multiple 多选后确认预览列表。
