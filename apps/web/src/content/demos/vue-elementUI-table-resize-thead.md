## 简介

Element UI Table 动态调整表头宽度并保持联动的实验页。用于后台表格可拖拽列宽场景。

## 如何测试验证

1. 拖拽表头边界，确认列宽变化。
2. 横向滚动时检查表头与表体是否对齐。
3. 窗口缩放后列宽是否错乱。
