## 简介

Phaser 3 教程相关静态页合集，适合作为浏览器端 2D 游戏引擎的入门演示：场景切换、精灵与输入等基础概念可从 `part1.html` 起逐步翻阅。

## 如何测试验证

1. 打开 part1，确认画布与示例资源加载成功。
2. 按页内交互试玩（移动/点击等）。
3. 切换同目录后续 part 页面，对照教程进度。
