## 简介

系统演示 HTML input 约束属性：type、pattern、min / max、minlength / maxlength 等与浏览器原生校验。

## 如何测试验证

1. 分别切换不同 type，输入合法 / 非法值。
2. 提交表单，观察原生提示文案。
3. 用 setCustomValidity 自定义错误信息（若页面支持）。
4. 对照 ValidityState 各字段。
