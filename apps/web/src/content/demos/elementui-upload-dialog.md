## 简介

Element UI 上传组件与弹窗进度展示：演示对话框内上传反馈。

## 如何测试验证

1. 打开上传弹窗，选择文件。
2. 观察进度条 / 成功失败状态。
3. 关闭弹窗再打开，确认状态是否残留。
