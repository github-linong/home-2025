## 简介

完整的「选图 → 裁剪 → 上传」小工程，演示前端在提交前如何约束画幅与局部区域。适合对照 H5 活动图、头像上传等场景。

## 如何测试验证

1. 选择本地图片，确认进入裁剪界面。
2. 调整选区 / 缩放，预览是否跟随。
3. 确认输出再走上传（若接口不可用，至少看到本地裁剪结果）。
