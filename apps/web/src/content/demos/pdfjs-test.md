## 简介

使用 Mozilla PDF.js 在浏览器中渲染 PDF，无需原生插件。适合文档预览、页码跳转等。

## 如何测试验证

1. 打开 Demo，确认 PDF 第一页渲染。
2. 翻页 / 缩放，检查清晰度与内存。
3. 换一份加密或损坏 PDF，观察错误处理。
4. 移动端滚动时注意 canvas 层数与性能。
