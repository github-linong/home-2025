## 0. 文档约定（Lean）
- 本圣经是 **jianghu 唯一视觉权威来源**；所有资产须对齐此处，偏离须标注并说明理由。
- 视觉一致性高于数量：任何资产偏离本圣经须回标 `【偏离】` 并说明。
- 像素与预算以 **2D Canvas + 浏览器低端机** 为硬约束；可访问性是基础要求，非锦上添花。
- 复用 dungeon-online 已验证的「色盲安全阵营色」「强提醒色 <8% 纪律」「telegraph 静态可读」纪律，避免重蹈覆辙。
- **已锁定风格：水墨像素（ink-pixel）**——像素底（`Nearest` 过滤 + 整数视口缩放）保 Canvas 性能，叠加武侠墨线轮廓（深色 ink-outline）与有限调色板；基础格 **48px native**（§6.4 已锁定）。

## 1. 世界观与视觉调性
### 1.1 一句话定位
> **"乱世江湖末路，侠影独行于将熄的城灯与苏生的妖氛之间——暖灯所及即是净土，灯外皆是可诛之敌；用克制的暗调、清晰的剪影与可读的预警，让任何浏览器里的玩家一眼分清『家』与『战场』。"**

Working-title 意象：**「灯尽处」**——灯火（城池/安全）与妖氛（荒野/地牢）是贯穿全作的视觉母题对立。

### 1.2 调性三元（综合参考拆解）
- **武侠（Wuxia）**：水墨笔意、飘逸长袍、刀光剑影、竹石远山、江湖肃杀。来源：剑侠情缘。
- **暗黑历史（Dark History）**：末世王朝、断壁残垣、烽烟焦土、压迫与荒芜。来源：秦殇（秦末暗黑历史感）。
- **暗黑奇幻（Dark Fantasy）**：妖异精怪、裂隙异象、幽冥地牢、哥特暗调。来源：魔域 / 暗黑破坏神。

### 1.3 情感弧（单图公共地图内的体验）
入城=归处（暖·安心）→ 出城=戒备（冷·转换）→ 荒野=孤绝（阴·危险）→ 裂隙=异变（紫·未知）→ 词缀成长=变强（橙紫辉光）。

### 1.4 避免（Do-Not · Tone）
- ❌ 卡通可爱 / 纯搞笑（与「肃杀感」冲突）。
- ❌ 写实血腥恐怖（gore 仅 stylized 暗示，不特写）。
- ❌ 纯黑压屏（用 `BG_DEEP` 替代，保细节）。
- ❌ 过度饱和霓虹（强提醒色总面积受 §2.6 纪律约束）。

### 2.6 强提醒色纪律（沿用 dungeon-online 红线）
- AMBER/LANTERN/DANGER/RIFT 为强提醒色，**非 telegraph 的 UI/装饰用途总面积 < 8%**，避免霓虹过载。
- **【DANGER 豁免 · 已锁定沿用】**：telegraph 预警区（敌人前摇/陷阱/AOE）**不计入** 8% 上限，改由「自身亮度（第 1 帧静态可读）+ 同屏数量预算（单屏 telegraph 上限，由怪物系统调度）」管理，保证弱网下可读。
- **稀有度/蓝怪 蓝碰撞预警**：`蓝 稀有 #4C7FD6`（宝蓝、词缀框）与 `蓝怪 钢蓝`（见 §5，偏青钢蓝+青色光环+精英图标）靠 **色相（宝蓝 vs 钢青）+ 上下文（词缀框 vs 怪物光环）+ 图标** 三重区分，不靠蓝色本身。

## 3. 光影与氛围（俯视 2D Canvas）
> 2D 叠加式光照；全部须在浏览器低端机可跑（Lean 预算）。【待引擎】
- **环境光**：顶层 `multiply`/`overlay` 暗化层——安全区压暖、刷怪区压冷，制造调性分野。
- **暖光母题**：LANTERN/AMBER 暖光 = 安全/城池信号（灯笼、灶火、安全区辉光）——呼应「灯尽处」。
- **玩家光源**：每玩家一个径向渐变光环（非阵营色中性光），兼作联机「同伴在场」指示。【待引擎】
- **战争迷雾**：基于玩家视野半径的可见多边形；**多人取各玩家视野并集（union）**。【待引擎】
- **体积感**：分层半透明 sprite（尘埃、烟、光束）模拟，禁用重型后期/模糊。
- **紧张感来源**：暗场 + 构图留白 + 暖光范围控制，而非血腥。

## 4. 角色风格（单主角武侠英雄）
> 单主角武侠英雄原型：剪影即可辨识；MVP 为**单一可成长英雄**，多人靠阵营色+名牌+装备剪影区分。【待GDD 确认是否多职业】

- **英雄剪影**：均衡挺拔、长袍飘逸、发髻/斗笠、背剑或持刀；头身比约 1:6（写实武侠感，非 Q 版），肩线利落。
- **辨识三件套**：剪影形状 + 阵营色描边 + 头顶名牌；三者任一缺失仍可辨识。
- **轮廓**：深色 ink-outline（2px native）使角色从环境「弹出」；受击态短暂 DANGER 描边闪烁（不靠细微动效）。
- **动作可读**：idle 呼吸 / walk 袍摆 / attack 刀光弧 / hurt 后仰；4 向（上/下/左/右）。
- **多人区分**：同模型 + 阵营色描边/名牌 + 武器/装备 silhouette 差异（刀/剑/枪/扇）；MVP 单职业则靠装备与名牌区分。
- **调色板**：单角色 ≤24 色（Lean 可控）；主色玄黑/墨青袍 + 朱砂束带点缀。

## 5. 怪物风格（三档：普通 / 精英 / BOSS）
> 分层可读性总原则：去饱和躯体 + 语义色 + 头顶图标；攻击必有**静态 telegraph**；关键区分复用「色相 + 上下文 + 图标」三重纪律，不靠单一颜色。【待GDD 定怪物类目】

### 5.1 普通怪（普通档）
- 小、多、锐角集群；去饱和冷躯体（CORPSE_BLUE/VOID 系）；红仅「即将攻击」时 DANGER 闪现。
- 含**精怪型小妖**（暗黑奇幻）：虚空紫/裂隙青微缠绕、不对称畸变轮廓，但尺寸仍属「普通档」、无常驻 aura。

### 5.2 精英怪（精英档 · 含蓝怪）
- 更大、专属剪影、常驻 **钢蓝 `#5F8FB0` 躯体 tint + 青色光环 `#5FD0E0` + 精英图标（王冠/双剑）**；区别于「蓝 稀有」宝蓝（§2.5，靠色相+上下文+图标三重区分）。
- 蓝怪为精英标准型；其余精英用同档视觉规则（更大尺寸 + 常驻 aura + 精英图标），aura 色可随主题变（如精怪型精英用紫青流）。

### 5.3 BOSS 视觉档（妖王 / 大妖 · BOSS 档）
> 区别于普通/精英：体量、能量密度、阶段化、专属登场与 telegraph 语言全面升级；仍复用「色相+上下文+图标」区分纪律，不靠单一颜色。
- **体量**：巨型多部件（native ≥ 3× 角色高，约 144–240px）；占据屏内显著视觉权重，天然与杂兵/精英拉开层级。
- **色**：多部件主色去饱和冷 + **阶段色**（每阶段切换主 aura 色，如 VOID 紫 → RIFT 青 → DANGER 红预警态）；阶段色仅用于 BOSS 自身，不与稀有度/蓝怪撞色（靠上下文+妖纹图标区分）。
- **常驻 aura**：强异象（RIFT 紫青漩涡 + 地面裂痕持续），强度高于精英青环。
- **图标**：专属**妖纹**图标（区别于精英王冠/双剑），头顶常驻 + 血条阶段标记。
- **telegraph**：攻击必有**明确 telegraph（静态形状 + 色块 + 声）**；AOE 直径 ≥ 3 tile，前摇 ≥ 0.6s 且第 1 帧自洽（弱网可读，§2.6 豁免）。
- **阶段化视觉**：每阶段切换轮廓光/能量色 + 地面异象升级；阶段切换有全屏轻暗 + 妖纹脉冲（§8）。

### 5.4 区分规则表（三档）
| 档位 | 子类型 | 尺寸 | 色 | 图标 | 常驻 aura |
|---|---|---|---|---|---|
| 普通 | 杂兵 / 精怪型小妖 | 小 | 去饱和冷 | 无 | 无 |
| 精英 | 蓝怪 / 精英 | 中 | 钢蓝 tint（或主题 aura） | 王冠/双剑 | 青环（或紫青流） |
| BOSS | 妖王 / 大妖 | 巨型 | 多部件+阶段色 | 妖纹 | 强异象漩涡 |

## 6. 环境与世界（三套环境语言）
### 6.1 安全区（城池/集镇 · 类似征途凤凰城）
暖色语言：城墙/屋身 WARM_STONE、木构 WOOD、招幌 BANNER_RED、灯笼 LANTERN 辉光；地面 TILE_WARM；天幕 WARM_NIGHT。NPC/商铺密集、灯火可交互（GOLD 描边）。**视觉承诺「不可被攻击」= 暖光覆盖 + 无危险纹理**。

### 6.2 刷怪区（荒野/洞穴）
冷色语言：CORPSE_BLUE 岩面、SICKLY 腐蚀植被、BONE 残骸、VOID 妖气；无建筑、留白制造孤绝；怪物出没区加 BONE 高光/暗苔提示「此处有敌」。洞穴子区更深、用 CORPSE_BLUE_DK + 局部 LANTERN 残光。

### 6.3 地牢入口（随机传送点）
醒目异象：RIFT 紫 + RIFT_TEAL 能量漩涡/裂隙，尺寸大于环境物、带持续脉冲 VFX（§8）与图标；在任一区域都「跳脱」当前调性，作为强引导 beacon。【待GDD 确认入口是否随机刷新位置】

### 6.4 Tileset 规格（草案）
- 基础格 **48px native（已锁定）**；图集分层：far 背景 → mid 道具 → floor/wall 主砖 → hazard 层 → foreground 暗角/光叠层。
- `Nearest` 过滤 + 整数视口缩放；支持 1×/1.5×/2× 显示缩放（可访问性/性能）。

## 7. UI 视觉方向（Canvas UI · 暗调一致）
- **HUD 贴边极简**：左上队伍面板（头像+血条+状态，阵营色）；底中技能/快捷栏；右上连接/延迟指示（多人必显 ping/重连）；顶部地图小窗（安全/危险区色块）。
- **血条**：角色头顶细条（阵营色底+白描边）；Boss 顶部长条+阶段标记（图标+文字三重编码）。
- **技能栏**：圆角石面格 + 阵营色激活辉光；冷却用环形遮罩（不靠变色）。
- **背包 / 词缀展示**：暗色卷轴/竹简面板；词缀按稀有度色框（§2.5）+ 图标 + 文字；hover 高对比 tooltip。
- **掉装提示**：屏幕右侧滚动击杀/掉落 ticker，稀有度色 + 图标 + 文字；传说/神话额外居中横幅 + 辉光 VFX。
- **浏览器适配**：Canvas 内 UI（不依赖 DOM）；响应式整数缩放；键鼠为主，触控可选回退。文字高对比（见 §9.2）。

## 8. 特效 VFX（攻击/技能/掉落/精英登场）
- **攻击**：刀光弧（阵营色/武器色）+ 命中火花（小、短）；
- **技能**：阵营色辉光冲击波 / 剑气 / 符箓展开；不与 DANGER 混淆。
- **掉落**：物品落地微光（稀有度色）+ 拾取上飘星点。
- **精英/精怪登场**：异象脉冲（RIFT 紫青漩涡）+ 地面裂痕 + 短暂暗角；Boss 登场加全屏轻暗 + 妖纹。
- **telegraph 预警**：静态形状（圆环/AOE 填充/弧/陷阱格）+ `#E5484D` 色块 + 图标；**第 1 帧自洽，不靠细微动效**（弱网可读）。
- 纪律：VFX 总面积受 §2.6 约束；装饰粒子可「减弱动效」关闭，静态预警 SHAPE 保留。

## 9. 资产规范初稿 + 可访问性基础
### 9.1 资产规范初稿（Lean）
- **格式**：PNG sprite / 图集（atlas）；源稿 2× 母版（tile 96px / 角色 96–144px），导出 `Nearest` + 整数对齐。
- **朝向/帧**：角色与敌人 4 向；idle 2 + walk 4 + attack 2 + hurt 1；动画帧独立于 tick，工程按网络插值。
- **命名**：`{category}_{name}_{facing}_{frame}`（如 `hero_swordsman_down_01`）；目录 `assets/{tiles|chars|mobs|ui|vfx|fx}`。
- **预算**：单角色调色板 ≤24 色；tileset 12–20 块/区；VFX 模板 4–6 可复用。
- **档位**：Basic=不可砍红线 / Standard=MVP 交付 / Comprehensive=后续里程碑。

### 9.2 可访问性基础（Colorblind-friendly + Contrast）
**目标分级：复用 dungeon-online 决策 = `Standard`（MVP 交付），Basic 为硬底线，Comprehensive 留钩子。**
- **色盲安全**：核心调色板通过 protan/deutan/tritan 模拟；关键语义**形状+图标+文字三重编码**，不依赖颜色。
- **对比度**：正文 ≥ WCAG AA 4.5:1；UI 文本力争 7:1。
- **文字缩放**：1.0×–1.5×（整数档，避免糊化）。
- **按键重映射**：多人必备，全功能键位可改 + 分键。
- **色盲模式开关**：替代调色板 / 叠加图案（危险物加斜纹）。
- **减弱动效**：关非必要粒子/抖动/屏震，**保留静态预警 SHAPE**。
- **事件文本化**：登场/Boss 阶段/掉落有文字提示，不只靠音/光。
- **Lean 硬底线（不可砍）**：安全核心调色板 + 达标对比度 + 按键重映射 + 颜色不单独编码 + 危险静态预警。
