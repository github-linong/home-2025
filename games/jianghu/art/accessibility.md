# 可访问性分级文档（Accessibility Tiers）· DRAFT v0.1（Phase 3）
> **状态：DRAFT v0.1 · 推荐 MVP 档 = `Standard`** ｜ 主理人确认用
> **对齐**：art-bible §2（调色板/阵营色）/§2.6（强提醒色纪律+ DANGER 豁免）/§4（角色三件套）/§5（怪物三重区分）/§7（UI）/§9.2（可访问性基础）
> **复用**：dungeon-online 已验证的「色盲安全阵营色」「强提醒色 <8%」「telegraph 静态可读」纪律，避免重蹈覆辙。

## 0. 文档定位与分级模型
- 本档是 art-bible §9.2「可访问性」的**分级展开**：把 MVP 可访问性基线拆成三档可执行清单 + 验收标准。
- 三级模型（包含关系 **Basic ⊆ Standard ⊆ Comprehensive**）：
  - **Basic（硬底线 / 不可砍）**：art-bible §9.2「Lean 硬底线」——缺一项即违反可读性与色盲安全纪律。
  - **Standard（MVP 目标档 · 推荐）**：本作在 Lean 预算下交付的可访问性集合（art-bible §9.2 已定 MVP=Standard）。
  - **Comprehensive（升级钩子）**：资源/时间允许时的增强，**留作后续里程碑**，不阻塞 MVP。
- 实现方：art-director 出**美术规格与判据**；engineering-lead 出**工程实现**。下表标注「归属（美术/工程）」与「实现成本（低/中/高）」。

## 2. 三档核心差异摘要
- **Basic**：仅保可读性与色盲安全底线（调色板 + 阵营色 + 对比度 + 三重编码 + 静态预警 + 重映射 + 剪影区分）。美术零额外资产，工程最小——是 Lean 不可砍红线。
- **Standard（MVP 推荐交付）**：在 Basic 上加「可切换」层——控制提示、字体缩放、减弱动效、色盲开关、静/动 telegraph 切换、UI 文字图标冗余、事件文本化。美术增量 = 图标集 + 斜纹图案 + 静态环形/阶段资产；工程增量 = 设置菜单 + 状态持久化。
- **Comprehensive**：把「可用」推向「舒适」——字幕/音频冗余、高级色盲自定义、自由缩放、全键盘、音频可视化、一键最大可访问性预设。增量主要在工程 + 美术扩展资产，**留作后续里程碑**。

## 3. 与 art-bible 的耦合
- 调色板（§2）已按色盲安全设计：阵营色 P1–P4 经明度/色相拉开；DANGER `#E5484D` 仅用于 telegraph（§2.6 豁免），外环境保持冷色，避免「暖红=危险」混淆（§12 决策 4）。
- 怪物三档（§5）靠「色相+上下文+图标」区分（普通无 aura / 精英青环+王冠 / BOSS 强异象+妖纹），不依赖单一颜色——直接满足 #4 三重编码。
- 角色三件套（§4：剪影+阵营色+名牌）满足 #6；HUD 文字高对比满足 #3/#13。

## 4. Standard 档验收标准（MVP 基线 · 推荐落地）
1. **色盲安全**：protan/deutan/tritan 模拟下，P1–P4 阵营色、DANGER、稀有度六档两两可区分；核心调色板通过模拟校验（#1/#2）。
2. **对比度**：所有 UI 文本 ≥ AA 4.5:1；HUD 关键文本（血/体/技能名/掉装 ticker）≥ 7:1（#3/#12）。
3. **字体缩放**：1.0×–1.5× 三档整数缩放，HUD 不溢出、像素字体不糊化（#9）。
4. **控制提示**：所有可交互物/技能有屏内提示或键位图例；首次进入有操作引导（#8）。
5. **按键重映射**：全功能键位可改 + 多人分键，设置持久化（#7）。
6. **reduced-motion**：开关生效，关非必要粒子/抖动/屏震；telegraph 静态 SHAPE 与危险预警保留（#10）。
7. **色盲模式开关**：可切换 alt 调色板或斜纹叠加，危险物可见（#11）。
8. **UI 文本可读**：状态/事件有文字+图标冗余；精英/Boss 登场、Boss 阶段、传说掉落有文字提示（#13）。
9. **静/动 telegraph**：弱网或偏好下强制静态预警（#14）。
