# UX 规格（ux-spec）

> 作者：design-strategist　|　版本：v0.1（Phase-4）　|　关联：concept.md（5 支柱）、design/gdd/*.md（7 系统）
> 目标：把 7 个系统 GDD 与概念文档的设计意图翻译成**玩家可见的界面/交互规格**。本文件给客户端/美术落地用，不写代码、不写美术资产。

---

## 0. 设计锚点（锚定 5 支柱，尤其 P5）
- **P5 即开即玩**：游客一键进、低认知负担、死亡不掉永久装（低挫败）。
- **P1 共闯**：co-op 名牌区分玩家、共享仇恨可见、入口集合点识别。
- **P2 拾装变强**：词缀对比提示、稀有度配色一眼辨。
- **P3 格挡反击**：输入/受击反馈清晰，格挡有顿帧火花。
- **P4 探入秘境**：地牢入口（裂隙异象漩涡）强识别、小地图区域指示。

## 1. HUD 布局
> 俯视 2D canvas，48px 网格（已对齐美术）。HUD 为屏幕覆盖层，不随地图滚动。

| 区域 | 元素 | 说明 | 来源 GDD |
|------|------|------|----------|
| 顶部/角色上方 | **血条（HP）** + **体条（VIT）** | 体条代"内力"（属性已去"内"，用体代内，显示名"体"），含数值/比例 | combat§③ / persistence§③ |
| 底部 | **技能栏** | 3–4 技能按钮，环形/数字 CD 回转显示；格挡为独立键 | combat§②·§⑥ |
| 角落 | **小地图 / 区域指示** | 安全区（暖色）vs 刷怪区（`DANGER` 8% 色标）色块；入口（裂隙）标记 | movement§② / spawning§② / dungeon§② |
| 头顶 | **co-op 名牌** | 玩家名，区分"自己/他人"配色；怪物无名牌 | auth§③ / persistence§③ |
| 击杀点 | **掉装飘字** | 掉落名 + 稀有度配色飘字（白/蓝/金/暗金） | loot§② |
| 背包/对比 | **词缀对比提示** | 新装 vs 当前装，绿升/红降箭头 | loot§② / persistence§③ |

- **死亡提示**：阵亡 → 淡出 → 在安全区复活（不掉永久装），低挫败反馈（P5）。

## 2. 输入映射
> 复用 wander 的网格步进 + 技能按钮（决策 B）；键鼠与触屏双适配。

| 动作 | 键鼠 | 触屏 |
|------|------|------|
| 网格步进移动 | WASD/方向键；或左键点目标格（寻路插值）**【Phase-2 待办（D8）：`targetTile` 未接线，MVP 仅方向步进】** | 虚拟摇杆 / 点按目标格（Phase-2） |
| 技能 1–4 | 数字键 1–4 / 点击技能按钮 | 屏幕技能按钮 |
| 格挡 | 右键 / 空格（受击前窗口内） | 长按专用格挡钮 |
| 交互（入口/拾取） | E / 自动拾取 | 自动拾取 / 点入口 |

- **预测与反馈**：移动输入本地预测 + 100ms 插值（R2，见 movement§⑧）；格挡/技能以服务端校验时间窗为准，不全量回滚。

## 3. 核心流程 UX（用户旅程）
1. **进入**：游客一键 / 登录自动加载角色 → 落安全区（P5 即开即玩，auth§⑥ / persistence§②）。
2. **区域认知**：暖色=安全、DANGER 8%=危险，小地图同步；新手靠色块一眼分辨（P1 可读性）。
3. **击杀拾取**：击杀飘字 → 自动入包；满 60 溢出落脚下地面（TTL 消失，无邮件，loot§⑤ / persistence§⑤）。
4. **背包 / 换装**：打开背包看词缀（tooltip 分层）；对比提示绿升红降，一键换装（persistence§③ / loot§②）。
5. **地牢入口**：识别裂隙异象漩涡 → 踩入触发独立随机副本，BOSS 置于深层（dungeon§②）。
6. **死亡复活**：HP≤0 → 在安全区复活，**不掉永久装备**（决策④，低挫败护 P5）。

## 4. 掉装 / 词缀展示规范
- **稀有度配色**：普通(白) / 精良(蓝) / 稀有(金) / 暗金(传奇) —— **复用 art-bible 色板**（art-director 产出后对齐；concept §6 已定"墨青+朱红+暗金"调性）。
- **tooltip 分层**（自上而下）：
  1. **名称**（按稀有度着色）
  2. **稀有度标签**（白/蓝/金/暗金 文字）
  3. **基础类型**（武器/防具/饰品）
  4. **词缀列表**：每条 `力/敏/体/ATK%/DEF/暴击/攻速/吸血/元素伤` + 数值
  5. **对比当前装备**：绿↑ / 红↓ 箭头（仅显示 delta）
- **认知过载防护（护 P5）**：白装无词缀时简化显示（仅名称+类型）；高级词缀才展开数值；tooltip 默认折叠、悬停展开。

## 5. 可访问性对接（Standard 档要点）
> 待 art-director 产出 art-bible 后，以本档要点对齐具体 token；以下为设计侧约定，不写最终数值。

- **对比度**：文字/UI 达 WCAG AA（≥4.5:1）；稀有度色不只靠颜色——叠形状/符号（如暗金加星标），色盲可辨。
- **不依赖颜色 alone**：安全区暖色 + 灯笼图标；危险区 DANGER 8% + 煞气符号；co-op 名牌用形状区分自己/他人。
- **可读性与触控**：正文 ≥14px，可选字号；触屏目标 ≥44px；技能 CD 同时有数字与环形进度。
- **反馈冗余**：格挡/受击除视觉外有顿帧/震感（若支持）；死亡有音画双反馈（与 audio 同学对齐）。
- **降级**：低带宽下 HUD 可简化（隐藏小地图网格线，保留分区色块）。

## 7. 开放问题 / 风险
- **art-bible 未出**：§4 稀有度色板、§5 可访问性 token 待 art-director 对齐（concept §6 已定方向）。
- **移动预测手感**：R2（100ms 插值）实测是否够用，Phase-3 程基岩可调。
- **触屏布局**：手机竖屏下 HUD 密度需真机走查，可能需折叠技能栏。
- **新手引导**：区域认知/PvE 纯合作目前靠色块+飘字，是否需首杀教学待 Phase-2+ 验证（护 P5 勿过重）。
- **浏览器客户端缺字段（design-review-s1 §3 → C1 设计侧输入，已决）**：MVP 用现有快照字段 `hp / maxHp / pos / skillCd / parryState / loot / entrance / phase` 渲染 HUD/小地图/掉装；以下 6 项缺字段归 Phase-2 补，客户端侧先按缺省/占位处理：
  1. `attrs`（STR/DEX/VIT 体条/属性面板）——数据面无（world 未回填）。
  2. `zone` / `inSafeZone`（小地图分区色块 / 安全区锁定）——快照无分区字段。
  3. 词缀定义表（affix id → 名称/数值区间/是否专属）——sim-core 仅 id 池，tooltip 无米下锅。
  4. `bossPhase` 序列化——world 内部有、协议未下发。
  5. `telegraph` 数据源——有 schema 无 world 生成（P3 预警渲染）。
  6. co-op 名牌名字——seatId → displayName 映射接口（join/room 控制面）。
