# GDD · 掉装系统（词缀 affixes / 稀有度 / 掉率）

> 系统编号：SYS-04　|　作者：design-strategist　|　版本：v0.1（Phase-2 初稿）
> 关联概念：concept.md §7.4、§8.3（P2 拾装变强；⑥ Boss 必掉更好词缀）

---

## ① 目标与范围
- **目标**：暗黑式随机词缀装备驱动 build（P2）；稀有度分档；BOSS 必掉更好词缀。
- **范围（含）**：稀有度判定、词缀池抽取、装备生成、掉落触发、入库、tooltip 分层。
- **范围（不含）**：战斗结算（归战斗）、经济交易（Phase-2）、装备穿戴 UI（归持久化/客户端）。

## ② 核心机制
- **稀有度分档**：普通(白) / 精良(蓝) / 稀有(金) / 暗金(传奇)。
- **词缀池（MVP 小池，三系属性）**：`力 STR / 敏 DEX / 体 VIT`、`ATK%`、`DEF`、`暴击率`、`攻速`、`吸血`、`元素伤`（金木水火土选 2–3）。
- **掉落规则**：
  - 普通怪：低概率掉白/蓝。
  - 精英：必掉，带 2–4 条词缀，稀有度加权。
  - **BOSS：必掉，稀有度加权更高（≥金，暗金概率提升）**。
- **装备生成**：按 `tier` 决定词缀条数 → 从池抽取（可重复属性不冲突则叠加）→ 数值按等级缩放。
- **保底**：连续 N 次未出金，提升下次权重（防长尾挫败，护 P5）。**【Phase-2 待办（D5）】MVP 为纯单掷（`rollLoot` 无 pity 计数，design-review-s1 D5）；连续 50 次无金 → 金权重 ×3 归 Phase-2。**

## ③ 数据模型 / 状态
```
Item {
  id, rarity,                 ; white|blue|gold|legendary
  baseType,                   ; 武器/防具/饰品
  affixes: [ {key, value%或值} ],   ; 来自词缀池
  ilevel,                     ; 决定数值缩放
}
AffixPool = [STR, DEX, VIT, ATK%, DEF, CRIT, APS, LIFESTEAL, ELEM×2~3]
DropTable { tier, dropChance, rarityWeights, affixCountRange }
RNG: 复用实例 seed（地牢内）或全局 seed（大图），保证可复现/可审计
```

## ④ 与其他系统依赖
- **刷怪系统**：击杀事件触发掉落；提供 `tier`（普通/精英/BOSS）决定 DropTable。
- **属性系统（角色）**：词缀映射 STR/DEX/VIT 等，影响战斗数值。
- **持久化系统**：掉落入库（登录玩家）；游客不持久（见持久化 §⑤）。
- **战斗系统**：击杀事件来源；BOSS 由战斗推进阶段后掉落。

## ⑤ 边界与异常
- **背包满**【已决·主理人推荐】：满 60 后溢出物品落脚下地面（TTL 自动消失），无邮件系统。与 persistence §⑤ 一致。
- **重复词缀**：同 key 多条 → 叠加数值（不冲突）；冲突规则由数值表定义。
- **游客不入库**：游客掉落仅会话内有效，退出即弃（防刷装舞弊，concept §8.2）。
- **掉率保底**：计数器跨掉落累计，入库前清零逻辑需明确。

## ⑥ 平衡初值
```
dropChance(普通) ≈ 0.30 ；dropChance(精英) = 1.0 ；dropChance(BOSS) = 1.0(加权更高)
稀有度权重: 白 60 / 蓝 30 / 金 9 / 暗金 1  (普通怪)
           蓝 40 / 金 45 / 暗金 15            (精英)
           金 55 / 暗金 45                   (BOSS，暗金显著提升)
affixCount: 白=0~1, 蓝=2, 金=3~4, 暗金=4 + 1 专属
保底: 连续 50 次无金 → 下次金权重 ×3   【Phase-2 待办（D5）：MVP 不实现 pity，纯单掷】
背包上限 = 60 格
```

## ⑦ 可测试性 / 验收
- **掉率统计**：10k 击杀，普通/精英/BOSS 掉率与稀有度分布符合 §⑥（±1%）。
- **词缀合法**：所有掉落词缀 ∈ AffixPool；数值在合法区间。
- **BOSS 加权**：BOSS 掉落暗金率显著高于普通（断言 ≥ 设计值）。
- **背包上限**：第 61 件触发地面掉落/拒绝。
- **验收标准**：词缀 100% 合法；保底触发正确；游客掉落不入持久库。

## ⑧ 开放问题 / 风险
- **经济失衡**：词缀装只产不出（无 sink）→ 通胀（concept §8.1）。MVP 宽松可接受，Phase-2 加打造消耗/交易税。
- **认知过载**：词缀池 + 属性 + 稀有度同时堆给新手 → 劝退（违背 P5）。缓解：tooltip 分层、白装无词缀、小池。
- **数值缩放**：ilevel 与玩家等级耦合曲线需与双线养成（XP=50·L^1.5）联调。
- **专属词缀**：暗金"+1 专属"的具体内容待定（建议与单职业剑侠主题绑定）。
