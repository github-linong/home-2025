# GDD · 刷怪系统（安全区 / 刷怪区 / 复活 / 精英 / BOSS）

> 系统编号：SYS-03　|　作者：design-strategist　|　版本：v0.1（Phase-2 初稿）
> 关联概念：concept.md §7.3、§8.3（决策⑥：普通/精英/BOSS 三档）

---

## ① 目标与范围
- **目标**：征途式节奏——安全区喘息、刷怪区练级、精英/BOSS 制造共闯热点（P1/P4）。
- **范围（含）**：地图分区、刷怪点复活、普通/精英/BOSS 三档生成与节奏、仇恨共享。
- **范围（不含）**：掉落计算（归掉装）、战斗结算（归战斗）、地图美术（归美术）。

## ② 核心机制
- **分区标记**：地图静态数据含 `zone` 字段（`safe` / `danger`），由移动系统读取决定 `inSafeZone`。
- **复活**：刷怪点按 `respawnTimer` 复活普通怪；刷怪点有容量上限，满则不补。
- **精英（蓝怪/精怪）**：按 `eliteChance` 概率在刷怪点刷新时升级为精英，属性与掉落加权。**【Phase-2 待办（D7）】MVP 为固定 15% 直配（`dungeonGen` 固定副本内精英率）；刷怪点级联掷骰（eliteChance 随机化）归 Phase-2。**
- **BOSS**：固定点位、长周期刷新（或手动触发），全图唯一（同点位不重复），必掉更好词缀。
- **仇恨共享（co-op）**：无组队 UI 下，同图玩家对同怪的攻击累加仇恨，怪物锁定最高威胁者（与战斗系统联动）。**【Phase-2 待办（D4）】MVP 无 threat 表（敌人按最近存活玩家接触攻击），仇恨表+安全区不可被锁定归 Phase-2（与 combat §② / movement §② 联动）。**

## ③ 数据模型 / 状态
```
SpawnPoint {
  id, gx, gy, zone,            ; 位置与分区
  monsterTier: normal|elite|boss,
  respawnTimer,               ; tick 或秒
  capacity, current,          ; 当前存活数
  nextRespawnTick,
}
Monster {
  id, tier, HP, ATK, def,
  eliteChance,                ; 该点精英概率
  bossPhaseState,             ; 仅 BOSS
}
MapZone { rect, type: safe|danger }   ; 来自地图配置
```

## ④ 与其他系统依赖
- **地图数据**：提供分区与刷怪点配置（美术/关卡提供坐标）。
- **掉装系统**：精英/BOSS 击杀触发掉落（必掉 + 稀有度加权）。
- **战斗系统**：提供目标与仇恨绑定、BOSS 阶段推进。
- **持久化**：击杀计数/任务进度（可选落库）。
- **移动系统**：读取分区决定安全区不可被锁定。

## ⑤ 边界与异常
- **分区越界**：`safe` 区不生成任何怪物；怪物不被允许进入安全区追击。
- **刷怪点满负荷**：达 `capacity` 停止复活，避免堆怪。
- **BOSS 唯一性**：同点位 BOSS 存活期间不重复刷新。
- **地图热更新**：分区变更需同步移动/刷怪缓存，避免状态撕裂。
- **玩家全离线**：刷怪点暂停计时，省算力。

## ⑥ 平衡初值
- 普通怪 `respawnTimer = 30–60s`；刷怪点 `capacity = 6–10`。
- `eliteChance = 15%`（**已决·主理人推荐：保持实现 15%，掉装向 MVP 更合适**；副本内精英率由 `dungeonGen` 固定 15%，大图刷怪点级联掷骰归 Phase-2 待办 D7）；精英 `HP/ATK ≈ 普通 ×3`。concept §7.3 的 `5%` 为早期草图，以本 GDD 为准。
- BOSS：固定点位，刷新周期长（如每 30min 一点位，或事件触发）；`HP/ATK ≈ 普通 ×10`。
- 安全区 `zone=safe` 永不生成/追击。

## ⑦ 可测试性 / 验收
- **分区断言**：安全区 100% 不出现怪物；危险区按配置生成。
- **复活计时**：刷怪点清空后 `respawnTimer` 内复活，误差 < 1 tick。
- **概率统计**：10k 次刷新，精英出现率 ≈ 15%（±1%）。
- **BOSS 唯一**：同点位同时存在 BOSS ≤ 1。
- **验收标准**：分区零泄漏；精英/BOSS 概率与属性符合 §⑥。

## ⑧ 开放问题 / 风险
- **多 BOSS 点位 / 世界 BOSS**：本期单点位，Phase-2 扩展（见 concept §5.2）。
- **动态难度**：是否按在线人数调整密度，待定。
- **BOSS 难度失衡**：需与战斗/掉装联调，避免碾压或劝退（concept §8.2）。
- **仇恨共享歧义**：无组队 UI 下"抢怪"感知，靠入口集合点 + 仇恨透明缓解。
- **Phase-2 待办（design-review-s1 O1 回填，原文保留）**：**D4** 仇恨表/锁定最高威胁 + 安全区不可被锁定（§② 已标）；**D7** 刷怪点级联精英掷骰（§②§⑥ 已标；MVP 固定 15% 直配）。
