# GDD · 随机地牢系统（入口 + 实例 + 分层 + BOSS）

> 系统编号：SYS-05　|　作者：design-strategist　|　版本：v0.1（Phase-2 初稿）
> 关联概念：concept.md §7.5、§8.3（决策 E：入口进独立随机副本；⑥ Boss 置于深层）

---

## ① 目标与范围
- **目标**：地图"入口"进服务端生成的独立随机副本（决策 E）；可选分层；BOSS 置于深层（P4 探入秘境）。
- **范围（含）**：入口触发、实例 seed 生成、房间拼接、独立刷怪/掉装、分层、深层 BOSS、出本回安全区、独立广播域。
- **范围（不含）**：房间美术（归美术）、战斗结算（归战斗）、掉落数值（归掉装）。

## ② 核心机制
- **入口**：地图固定"入口"格，视觉为**裂隙异象漩涡**（已对齐美术）；玩家踩入 → 触发进入。
- **实例生成**：`instanceSeed = hash(serverTick + entranceId + partyTag)`；用 seed 驱动房间模板随机拼接（5–12 间）。
- **独立域**：副本内刷怪/掉装/广播均为独立实例域，不与大图混流。
- **分层（可选）**：副本可多层，逐层难度升；**BOSS 置于最深层**。
- **出本**：击杀/主动退出 → 回大图安全区；副本超时解散。
- **成员锁定**：进入瞬间锁定副本成员（含单人），掉线可重连回本或安全区。

## ③ 数据模型 / 状态
```
Instance {
  id, seed,
  rooms: [ {templateId, gx, gy, monsters[], loot[]} ],
  depth, maxDepth,             ; 分层
  members: [userId],           ; 进入时锁定
  bossPlaced: bool,            ; 最深层
  createdTick, expireTick,     ; 寿命
}
Entrance { gx, gy, cooldownTicks, lastUsedTick }
```

## ④ 与其他系统依赖
- **刷怪系统**：副本内按实例 seed 生成普通/精英/BOSS（最深层）。
- **掉装系统**：副本内掉落（BOSS 必掉更好词缀），RNG 复用 `instanceSeed` 保证可复现。
- **移动 / 战斗**：进入/离开切换坐标系与广播域；战斗在副本域内结算。
- **持久化**：副本进度为临时态（不长期落库）；角色/背包跨刷新仍保留。

## ⑤ 边界与异常
- **同本成员锁定**：进入后新玩家不可中途加入（除非 Phase-2 扩展）；避免实例归属混乱。
- **掉线重连**：回原副本（若在寿命内）或安全区（已超时/解散）。
- **副本超时**：`expireTick` 到达 → 解散，存活成员回安全区，未拾取掉落消失。
- **入口冷却**：防刷本，`cooldownTicks` 内同入口不可重复触发。
- **单人可进**：不强制组队（护 P1 无组队 UI）。

## ⑥ 平衡初值
- 房间数 `5–12`；分层 `maxDepth = 3`（第 3 层置 BOSS）。
- 实例寿命 `expireTick = 30min`；入口冷却 `10s`。
- 副本内刷怪密度 ≈ 大图刷怪区 ×1.5；深层 BOSS 属性同刷怪系统 BOSS 档。**【已决·主理人推荐：MVP BOSS 为 2 阶段 @50% hp（`BOSS_PHASE_THRESHOLD=0.5`，见 combat §⑥）；3 阶段（66%/33%）+ 特殊技归 Phase-2（D1）。】**
- `partyTag`：单人=自身 id，多人=进入时首个触发者 id（保证同队同本）。

## ⑦ 可测试性 / 验收
- **seed 可复现**：同 seed 生成房间布局/掉落完全一致（断言哈希一致）。
- **成员锁定**：进入后第 2 人无法加入同实例（断言 members 不变）。
- **BOSS 位置**：最深层必含 1 个 BOSS（断言 `bossPlaced`）。
- **出本回安全区**：退出后坐标在大图安全区（与移动系统联测）。
- **广播隔离**：副本内聊天/位置不泄漏到大图房间（与 chat 广播联测）。
- **验收标准**：100 次生成 0 例 BOSS 不在深层；seed 复现率 100%。

## ⑧ 开放问题 / 风险
- **多人实例归属**：`partyTag` 若多人几乎同时踩入口，需明确谁锁定（取先到者）。建议入口做"集合缓冲"：踩入后短等待同图邻近者。
- **副本内死亡惩罚**：MVP 死亡不掉永久装（决策④），但副本内可设临时惩罚（Phase-2）。
- **世界 BOSS**：本期副本 BOSS，全图定时世界 BOSS 归 Phase-2（concept §5.2）。
- **RNG 安全**：seed 不可被客户端预测篡改（服务端权威生成）。
