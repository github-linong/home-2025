# GDD · 移动系统（grid-step）

> 系统编号：SYS-01　|　作者：design-strategist　|　版本：v0.1（Phase-2 初稿）
> 关联概念：concept.md §7.1、§8.3（决策 B：网格步进 + 技能按钮；决策⑤：俯视 2D 48px）

---

## ① 目标与范围
- **目标**：在服务端权威下提供可读、可预测的实时网格步进移动，支撑 co-op 同图共闯（P1）与即开即玩（P5）。
- **范围（含）**：玩家网格移动、tick 位置广播、占用格碰撞、安全区/刷怪区位置语义。
- **范围（不含）**：物理推挤、载具、技能位移（归战斗系统）、寻路 AI（归刷怪系统）。

## ② 核心机制
- **网格**：tile = **48×48px**（已对齐美术：水墨像素），全图整数格坐标 `(gx, gy)`。
- **tick 同步**：服务端以 `tickRate = 12 tick/s`（允许 10–15）推进，每 tick 广播订阅房间内玩家位置。
- **输入→校验→广播**：客户端发送方向/目标格 → 服务端校验合法性（不穿墙、不越界、目标格未占用）→ 更新 authoritative 位置 → 广播。**【Phase-2 待办（D8）】点目标格（`targetTile`）已声明未接线（types.ts），MVP 仅支持方向键/WASD 方向步进（见 ux-spec §2）。**
- **碰撞**：每玩家占用 1 格；移动目标格被占则拒绝（排队或失败反馈）。
- **安全区语义**：玩家处于安全区标记格时，不可被任何怪物锁定（与刷怪系统联动）。**【Phase-2 待办（D4）】MVP 未计算 `inSafeZone`（快照无 zone 字段），怪物按最近存活玩家接触攻击；安全区不可被锁定归 Phase-2（与 combat §② / spawning §② 联动）。**

## ③ 数据模型 / 状态
```
TILE_PX = 48                      ; 像素/格 (const, 已对齐美术)
TICK_RATE = 12                    ; tick/秒
BASE_SPEED = 4                    ; 格/秒 (玩家基础)
PlayerMoveState {
  userId, gx, gy,                 ; 当前格
  tx, ty,                         ; 目标格
  moveStartTick, arriveTick,      ; 插值用
  inSafeZone: bool                ; 安全区标记（由地图分区数据推导）
}
```

## ④ 与其他系统依赖
- **认证 / 持久化**：身份校验后才能入场；位置可选落库（断线恢复）。
- **战斗系统**：站位是技能命中/格挡判定的前置；技能释放期间移动约束由战斗系统下发。
- **刷怪系统**：读取地图分区数据判定 `inSafeZone`，决定怪物是否锁定该玩家。
- **随机地牢**：进入/离开副本切换广播域与坐标系（副本内独立）。

## ⑤ 边界与异常
- **断线重连**：恢复最后落库位置；无落库则回安全区。
- **非法移动**（瞬移/穿墙/越界）：服务端拒绝并回滚到上一合法格。
- **双输入冲突**：同 tick 多方向输入取最后一条，校验失败则不移动。
- **边界外**：地图边缘做夹取，禁止移出 `[0, mapW-1]×[0, mapH-1]`。

## ⑥ 平衡初值
- `TICK_RATE=12`、`BASE_SPEED=4 格/秒` → 每格约 3 tick（250ms）步进。
- 网格尺寸 48px；地图建议 64×64 ~ 128×128 格。
- 碰撞占用单格；安全区不生成怪物（见刷怪系统）。

## ⑦ 可测试性 / 验收
- **单元**：给定方向序列，断言路径不穿墙、不越界、终格合法。
- **同步**：注入 80–200ms 人为延迟，断言服务端 authoritative 位置正确、客户端插值无永久漂移。
- **安全区**：玩家进入安全区格后，怪物仇恨列表不含该玩家（与刷怪联测）。
- **验收标准**：1000 次随机移动模拟 0 穿墙；延迟下位置误差 < 1 格。

## ⑧ 开放问题 / 风险
- **客户端预测 + 服务端回滚**【已决·主理人推荐】：采用「移动输入预测 + 100ms 插值；格挡/技能服务端校验时间窗，不做全量回滚」（R2 工程解）；仍可在 Phase-3 由程基岩架构验证微调（见 combat §⑧）。
- 48px 与现有 wander 网格步进参数是否一致？需程基岩确认复用成本。
- 高并发同格争用（入口集合点）是否需要队列/一人占位，待联调。
