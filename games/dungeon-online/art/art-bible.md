## 0. 文档约定（Lean）
- 本圣经是**唯一视觉权威来源**，资产须对齐此处；偏离须标注并说明理由。
- 标注：`【待引擎】`= 与程基岩核对 Godot 4/Web 能力；`【待GDD】`= 等系统设计定类。
- 像素与预算以 2D + Web 性能为硬约束。

## 1. 核心视觉身份陈述（一句话定位）
> **"可读性优先的像素地牢合作——阴森中透着余烬暖光，敌人很凶但和队友在一起很安心；用明亮阵营描边与清晰预警，让 2–4 人在任何浏览器里一眼读懂战局、协同破局。"**

Working-title 意象：**余烬小队（Ember Squad）**——黑暗中的暖光即"同伴/安全"的视觉母题。

## 2. 情绪与基调（Mood & Tone）
- **Mood**：阴森中带温暖、危险中带可爱（cozy-dark + eerie）。紧张感来自**光照与构图**，而非血腥。
- **Tone**：合作、冒险、俏皮；敌人凶悍（锐角剪影）但队友亲切（圆润微 Q 比例），"和队友在一起很安心"。
- **情感弧**：入本=未知 → 见队友暖光=不孤单 → 清晰预警=可控的紧张 → 击败=我们做到了。
- **避免**：血腥/写实恐怖、纯黑压屏、靠细微动作暗示危险。

## 3. 配色方案（具体 HEX）【已按锚点收敛】
> 低饱和冷色基底 + 暖色专用于"安全/协作"信号；关键语义**不以颜色单独编码**（见 §10）。

### 玩家阵营色（4，色盲安全；取冷/品红/绿族，预留暖区给环境信号）
| 玩家 | HEX | 备注 |
|---|---|---|
| P1 蔚蓝 | `#4CB5F5` | 高饱和蓝，色盲最稳 |
| P2 紫罗兰 | `#9B7BE8` | 冷紫，与品红靠明度区分 |
| P3 品红 | `#E86FB0` | 粉紫，弥补绿盲区分 |
| P4 春绿 | `#6FD68A` | 高明度绿，配剪影/图标防混淆 |

> 玩家色**仅**用于角色描边/名牌/自身技光效；暖色 GOLD/EMBER **仅**用于环境/协作，避免语义混淆。
> **纪律**：GOLD/EMBER/DANGER 为强提醒色，**非 telegraph 的装饰/UI 用途**总面积 < 8%，避免霓虹过载。
> **【DANGER 豁免 · 用户批准】telegraph 预警区例外**：战斗中敌人攻击前摇 / 陷阱 / AOE 的 DANGER 预警区**不计入**全局 8% 占比，改由「自身亮度（自第 1 帧静态可读，不靠细微动效）+ 同屏数量预算（单屏并存 telegraph 数上限，由 ⑧ 敌人与 AI 调度）」管理，以保证 P3「读得懂的紧张感」在任何网络延迟下稳定可读。仅"非 telegraph 的 UI / 装饰"仍须遵守全局 <8% 纪律。本豁免与 `accessibility.md` 不冲突——accessibility 约束的是"界面/装饰强提醒色不可过载"，telegraph 属功能性游戏预警，按可读性硬约束（§7）单列管理。

## 4. 造型与剪影语言（Shape Language）【已按锚点收敛】
**核心原则：剪影即可读性；英雄可爱可信、敌人凶悍可畏。**
- **英雄（友方）**：圆润、微 Q 比例（头身约 1:1.5）、对称、紧凑；传递"可接近、可信赖"。
- **敌人（敌方）**：锐角、尖刺、不对称、锯齿化轮廓；去饱和躯体 + 攻击态 DANGER 描边；传递"危险、异质"。
- **"凶但可爱"平衡**：怪物可带夸张大眼/圆钝武器等萌点，但轮廓仍锐角化以保敌我辨识。
- **环境**：正交像素砖块 + 有机破损叠层（裂纹、苔藓、流痕）软化生硬感。
- **可交互物**：统一"圆角方框 + GOLD 描边"母题，与墙体锐角对比。
- **差异化三件套**：剪影形状 + 阵营/语义色 + 头顶图标，三者任一缺失仍可辨识。

## 5. 光影与氛围（Lighting & Atmosphere）【已按锚点收敛】
> 2D 叠加式光照；全部须在 Web 低端机可跑（Lean 预算）。【待引擎】
- **环境光**：`CanvasModulate` 压暗至冷蓝填充。
- **暖光母题**：GOLD/EMBER 暖光 = "安全/协作"信号（营地、安全区、协作技辉光）——呼应余烬小队。
- **玩家光源**：每玩家一个 `Light2D` 径向渐变（火炬/光环）——兼作联机"同伴在场"指示。
- **战争迷雾**：基于玩家视野半径的可见多边形；**联机取各玩家视野并集（union）**。【待引擎】
- **体积感**：分层半透明 sprite（尘埃、光束）模拟体积雾，禁用重型后期。
- **紧张感来源**：暗场 + 构图留白 + 暖光范围控制，而非血腥。

## 6. 角色 / 怪物风格方向（像素风）【风格已定：像素风】
- **风格**：像素艺术，干净平涂 + 2–3 阶卡通明暗；base tile 32px，角色 32–48px 高（微 Q 比例保可读）；`Nearest` 过滤、整数缩放。
- **英雄（4 原型，待 GDD 定类）**：守卫士（圆盾宽肩）、游侠（细长敏捷）、术士（尖帽飘带）、医者（十字/光环）；每人固定 **阵营色描边 + 职业图标 + 独特剪影**。单角色调色板 ≤ 16–24 色（Lean 可控）。
- **怪物（分层可读性）**：
  - 杂兵：小、多、锐角集群；红色仅"即将攻击"时闪现。
  - 精英：更大、专属剪影、常驻 DANGER 描边。
  - Boss：巨型多部件、阶段化；攻击必有**明确 telegraph（静态形状 + 色块 + 声）**。

## 7. 地牢场景视觉语言（像素 Tileset）【强化可读性硬约束】
### Tileset 规格
- **基础格 32px**；图集分层：far parallax 背景 → mid 道具 → floor/wall 主砖 → hazard 危险层 → foreground 暗角/光叠层。
- 源稿按整数倍制作；引擎 `Nearest` + 整数视口缩放；支持 1×/1.5×/2× 显示缩放（可访问性/性能）。

### 可读性硬约束（承接 P3「读得懂的紧张感」+ Web 延迟宽容）
- 所有危险（**敌人攻击前摇 / 陷阱 / AOE**）**必须有明确轮廓或色块预警**，从第一帧即可读；**不得仅依赖细微动画或帧精确微动**暗示。
- 预警须为**静态可读形状**（telegraph 圆环、危险格描边、AOE 填充）+ 叠加 DANGER 色块。
- 网络延迟下仍可读：建议前摇 **≥ 0.6s** 且静态形状自第 1 帧存在（已锁 ADR-NET-01 D3:18tick@30Hz）。
- 其余可读性原则：地面中性永远"可走"；墙体顶面 STONE_HI 高光 = 不可走；危险物 DANGER 色块 + 图标纹理（不靠色 alone）；敌人去饱和 + DANGER rim；玩家阵营色光环 + 名牌；战利品/门 GOLD；一致描边使实体"弹出"；共享迷雾取并集。

## 8. UI/UX 视觉方向（像素一致）
- **HUD 贴边极简**：左上队伍面板（4 头像 + 血条 + 状态，阵营色）；底中技能/快捷栏；右上连接/延迟指示（权威服务器必显 ping/重连）；世界内倒地/救援用图标 + 环形进度（不靠变色）。
- **菜单**：石面面板 + GOLD 描边 + 圆角（呼应 Shape Language）；像素字体（crisp）。
- **联机指示**：头顶名牌（阵营色）、地图 ping 标记、队伍状态同步。
- **浏览器适配**：Godot Canvas UI（不依赖 DOM）；响应式整数缩放；键鼠为主，触控可选回退。
- **文字**：最小可读字号、高对比；见 §10。

## 9. 参考板 + 明确"不要做什么"（Do-Not）【风格已定像素】
**参考板（方向性，非抄袭）**
- 像素地牢/动作：*Nuclear Throne*、*Moonlighter*、*Cobalt Core*、*Forager*（像素 2D 可读性与氛围）。
- 调性参考：*Hades*（爽快可读）、*Enter the Gungeon*（俯视可读）、*Stardew Valley*（舒适配色）、*The Binding of Isaac*（tileset 变体）、*Deep Rock Galactic*（联机色编码）。

**Do-Not（明确禁止）**
1. ❌ 写实/PBR 重材质（Web 性能 + Lean 不划算）。
2. ❌ 任何关键信息只用红/绿编码。
3. ❌ HUD 叠在玩法区造成遮挡。
4. ❌ 玩家与敌人剪影在瞬间不可区分。
5. ❌ 过小/低对比文字或像素字体糊化。
6. ❌ 纯黑背景（压死细节，改用 BG_DEEP）。
7. ❌ **仅用细微动效暗示危险**（P3 硬约束，Web 延迟下不可靠）。
8. ❌ 强调色过载 / 暖色误用于玩家身份（混淆安全语义）。
9. ❌ 描边宽度/像素网格不一致破坏识别。

## 10. 可访问性（Accessibility）
**目标分级：Lean 下定为 `Standard`（基础可达），预留升至 `Comprehensive` 的钩子。**
- **色盲安全**：核心调色板通过 protan/deutan/tritan 模拟；关键语义**形状+图标+文字三重编码**，不依赖颜色。
- **对比度**：正文 ≥ WCAG AA 4.5:1；UI 文本力争 7:1。
- **文字缩放**：提供 1.0×–1.5×（像素 UI 用整数档位）。
- **按键重映射**：联机必备，全功能键位可改；支持多人分键。
- **色盲模式开关**：切换替代调色板 / 叠加图案（如危险物加斜纹）。
- **减弱动效**：关闭非必要粒子/抖动/屏震（注意：危险预警的**静态形状**须保留，仅去装饰动效）。
- **事件文本化**：重要事件（倒地、Boss 阶段、救援）有文字提示，不只靠音/光。
- **Lean 最低交付（硬底线，不可砍）**：安全核心调色板 + 达标对比度 + 按键重映射 + 颜色不单独编码 + **危险静态预警（P3）**。
