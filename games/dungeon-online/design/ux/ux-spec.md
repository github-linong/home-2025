## 1. 进入流程（对接 ① ④ ②）

- **好友房**：任一客户端「创建房间」→ 服务器分配 `room_id` + **6 位房间码（base32，排除 I/O/0/1）** + 邀请链接（含一次性 token）；房间码/链接分享即可加入，**2–4 人**，满员拒绝。
- **公共体验房（RESIDENT 常驻入口）**：Web 端（lilnong.top）即开即玩入口，**无房间码、任意加入**；服务器进程级常驻，不经历 `LOBBY`/`CLOSED` 常态流转，玩家加入/离开仅为「在场集合」变更；仍守断线托管/重连（P4）。
- **LOBBY 集结**：选职业（② 职业接口：坦/输出/辅助/控场）→ 准备 → 开局。**co-host 提示**：按加入顺序自动授予前序队员为联席主持人（权限=房主同权：踢人/开局/改设置；上限建议 ≤2）。房主掉线→管理权**自动迁移**至下一位 co-host / 顺位队员，房间不关（契合 P4）。
- **solo 降级**：**1 人即开局**，走完整核心循环（探→战→拾→商→下→Boss→结算）；协同类机制降级（商 Regroup 退化为自处理、救援退化为自救读条）。
- **输入映射预留**：多人分键在 LOBBY/设置即生效（对齐 §3 与 accessibility #6）。

## 2. 核心循环 UX（对接 ① ⑤ ⑦ ⑧ ⑬ ⑥ ⑫ ②；⑨ 预留）

核心动词：**探 → 战 → 拾 → 商 → 下 → Boss → 结算**（systems-index §3 已校验无缺口）。

- **探 Explore（① ⑤ ⑬）**：战争迷雾**取各玩家视野并集（union）**——已探索/未知以**静态形状**区分（⑤§7）；HUD 聚合并集多边形（⑬ 接口预留，引擎 Light2D/可见性多边形）。
- **战 Fight（⑦ ⑧ ④ ⑬；⑨ 预留）**：
  - 敌人攻击 telegraph **第 1 帧可读**（⑧§7）：静态可读形状 + DANGER 色块 + 声；前摇 **≥0.6s（18 tick）**，杂兵 21 / 精英 24 / Boss 30 tick（满足 P3 不等式，弱网下可读紧张感不崩塌）。
  - 玩家操作反馈（④）：本地预测表现「跟手」→ 服务器结算 → 回正(reconciliation) + **插值 100 ms** 平滑（无瞬移误导战局）；高延迟时 HUD 提示「延迟高，表现已平滑」。
  - **⑨ 协作技（待 ⑨ GDD 补完回填）**：HUD 技能栏预留协作技触发入口（如坦护盾墙/医者救援链/控场的合围），其连携判定与协同增益结算 UX 待 ⑨ GDD 定稿后回填本§。
- **拾 Loot（⑤ ⑥）**：资源节点用 **GOLD 描边**（art-bible §4，与阵营色/危险色语义隔离）；固定放置（非程序化掉落），拾取进入队伍/个人库存。
- **商 Regroup（⑩ ⑥ ⑬ ⑤）**：层间休息点标记（⑤ 产出）作为谈判窗口——信号沟通（⑩）+ 资源实时分配（⑥）+ HUD 呈现（⑬）。**不立独立安全屋系统**（systems-index §2.4 范围纪律）。
- **下 Descend（⑤ ⑫）**：楼层推进由 ⑫ 进度触发、⑤ 生成新层（确定性 seed，同 seed 同布局）。
- **Boss（⑧ ⑦；⑨ 预留）**：Boss 分阶段（⑧），攻击 telegraph 更显著（形状更大 + 声 + 阶段提示文字）；战斗胜负由 ⑦ 裁定、⑫ 触发通关。
- **结算 Settle（⑫ ⑥ ①）**：通关/团灭 → ⑫ 结算（资源清点 + 得失）→ 回 `LOBBY`（再来）或 `CLOSED`（好友房销毁；公共房常驻不销毁）。

## 3. 输入映射（对接 ④ ②；accessibility #6）

- **输入指令 schema（④/ADR D6）**：`InputCmd{ seq, tick, action, dir, target?, param? }`，action ∈ {MOVE / ATTACK / DODGE / SKILL / SIGNAL}；渲染帧(60fps)采集，**每 tick（30 Hz）上报**。
- **键盘 / 手柄双支持**：移动、普攻、闪避(i-frame)、技能、信号五类动作；**多人分键**——全功能键位可重映射 + 每人独立键位集（accessibility #6，**Basic 不可砍**）。
- **客户端预测反馈（④§3/§6）**：本地预测位移/普攻表现（不等待服务器）；收权威 diff 后回正重演保留 ~6 条未确认指令（预测缓冲 `ceil(RTT/2/TICK_MS)+2`，RTT250→~6）；远程玩家/敌人按 **插值 100 ms** 平滑。
- **延迟指示（①§7）**：HUD 显 ping(ms) + 连接质量，用**橙/绿图标 + 文字三重**（不靠色 alone），高延迟提示「延迟高，表现已平滑」降低误读。
- **⑨ 协作技输入（待 ⑨ GDD 补完回填）**：协作技触发键位/组合与连携输入语义待 ⑨ 定稿后补入本§。

## 4. HUD 布局（对接 ⑬ ① ⑦ ⑧ ②；accessibility #2/#3/#5/#9/#13/#14）

极简贴边、不遮挡玩法区（art-bible §8）；所有语义**色盲三重编码**（accessibility #3）。

- **左上 · 队伍面板（⑬ ① ②）**：4 头像 + 血条 + 状态；**阵营色描边/名牌**（①§7：P1 蔚蓝 / P2 紫罗兰 / P3 品红 / P4 春绿，art-bible §3），仅用于角色描边/名牌/自身技光效。
- **底中 · 技能/快捷栏（⑬ ⑦）**：普攻/闪避/CD（⑦ 提供 HP/状态/CD 数据 → ⑬）；协作技槽位预留（⑨ 待回填）。
- **右上 · 连接/延迟指示（⑬ ①）**：权威服务器必显 ping + 重连状态（**橙绿图标 + 文字三重**，①§7）；断线时显「托管中/重连中」。
- **世界内 · 战争迷雾并集（⑬ ① ⑤）**：已探索/未知静态形状区分；并集多边形由 ① 提供、⑬ 渲染。
- **世界内/Boss · 敌人血条与 Boss 血条（⑬ ⑧）**：敌人 HP/状态/Boss 血条数据由 ⑧ → ⑬；Boss 阶段提示文字（accessibility #13 事件文本化）。
- **可访问性**：正文对比度 ≥ AA 4.5:1（accessibility #2），力争 7:1（#14）；字体缩放 1.0×–1.5× 整数档（#10，Standard）；色盲模式开关（#8，Standard）；减弱动效保留静态预警形状（#11/#12，Standard）。

## 5. 救援/倒地交互（对接 ⑪ ⑩ ⑦ ①；accessibility #3/#7/#13）

- **DOWNED 触发（⑦→⑪）**：HP≤0 → 战斗置 `DOWNED`（不死、不销毁）；**免疫补刀致死**（MVP 不做补刀致死，敌可持续攻击但仅维持 DOWNED 计时）——保 P4 友好、降劝退。
- **呼救（⑩→⑪）**：DOWNED 经 ⑩ 信号广播「急救！」——世界内标记 + HUD 图标 + 文字（三重编码，⑪§7）。
- **救援 / 自救读条（⑪ ⑬）**：静态**环形进度 + 图标**（不靠变色，art-bible §8/⑪§7）；≥2 人队友靠近读条 **3 s** 归队；**solo 自救读条 5 s**（①§5 降级分支）。
- **超时→OUT 观战提示（⑪§3/§5）**：DOWNED 窗口 **15–20 s** 未救援 → 该玩家 `OUT`（**本局观战**，下局重置 ALIVE；不影响 ALIVE 队友继续推进，团灭才结算）。HUD 显「已出局·本局观战」文字（accessibility #13）。
- **阵营色（⑪§7）**：倒地玩家描边用**自身阵营色 + 弱化**（仍辨识），不混淆 DANGER。
- **事件文本化（accessibility #13）**：倒地/Boss 阶段/救援均有文字提示，不只靠音/光。

---

## 6. 信号系统（对接 ⑩ ④ ① ⑬；accessibility #9）

- **信号类型（⑩）**：急救 / 集合 / 危险 / ping 标记 / 表情；经 `InputCmd.action=SIGNAL` 上报（④ schema），由 ① 广播。
- **UX 呈现（⑬ ⑩）**：世界内 ping 标记 + HUD 信号图标 + **文字标签**（accessibility #9 文字+图标冗余）；急救信号直连 ⑪ 呼救广播（§5）。
- **多人分键（accessibility #6）**：信号快捷键全功能可重映射、每人独立，与战斗键位分键不冲突。
- **⑨ 协作技信号联动（待 ⑨ GDD 补完回填）**：协作技连携所需的协同信号（如「合围」「护盾就位」）语义待 ⑨ 定稿后补入。

## 7. 断线重连 UX（对接 ① ⑪ ⑦；P4 保底；accessibility 无专属项）

- **断线检测（①§3/ADR D1.6）**：服务器心跳 **5 s 无响应**判断线（绝对阈值，高延迟不误判）；不立即销毁角色，进入**托管/冻结**（保留 slot + 权威状态）。HUD 显「队友托管中」。
- **托管提示（① ⑪）**：托管期间角色状态由 ① 保留、⑪ 冻结其 DOWNED/救援计时（不终止循环，契合 P4）。
- **重连归位无跳变（①/⑪/⑦ + ADR D8）**：凭 `room_id` + 身份 token 重连 → ① 从权威快照恢复；**P4 保底契约**：托管期间 DOWNED 与救援读条**计时暂停**，重连**还原至掉线瞬间原状态（含剩余窗口）**，目标 = 掉线瞬间 `DOWNED`/`ALIVE`，**不误判超时→OUT**。机制（ADR D8）：断线瞬间抓拍完整 PersonalState（含 DOWNED 标志 + 剩余窗口 ticks + 救援进度）冻结持有；重连先收当前 room 权威态（他人已动），再以保留 PersonalState 覆盖还原 → 自身回到掉线瞬间，两对象分离防跳变。
- **co-host 迁移（①§3/§5）**：房主 `DISCONNECTED` → 管理权自动迁移至 co-host / 下一顺位，房间继续（不进 `CLOSED`）。
- **公共房（ADR D11）**：RESIDENT 常驻，重连同流程（sticky 路由 + 进程存活 keepalive）；玩家进出仅为在场集合变更。
