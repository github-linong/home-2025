# GDD ⑧ 敌人与 AI 系统（Enemy & AI）
**路径**：`games/dungeon-online/design/gdd/08-enemy-ai.md` ｜ 标记：`[MVP][P3]`
**依赖（systems-index §2）**：依赖 ⑤ 刷怪点（L1）+ ⑦ 战斗（伤害请求协议，L2）+ ② 角色与职业（状态模型，L0）；被依赖 ⑬。
**循环依赖纪律 B（systems-index §2.3）**：本系统**只决策行为并发出「伤害请求」交由 ⑦ 裁定，不 import ⑦ 战斗运行时**；战斗是通用结算权威，不依赖本系统。代码/文档边界须标注此纪律。

## 1. 目的与支柱对齐
解决敌人行为、刷新与攻击表达，闭合 战 循环，是 **P3「读得懂的紧张感」的落地处**（telegraph）与 Boss 体验来源。服务 P3。不自行结算伤害（归 ⑦）。

## 2. 依赖与上游接口（修订后，引用 schema + 只读不调标注）
- **依赖**：
  - ⑤ 地牢生成（**刷怪点实例数组 `SpawnPoint[]`，单一 schema 见 ⑤ §3**）：本系统**只读不调**——严禁反向调用 ⑤ 的布局/随机生成函数（纪律 A 字段级边界，见 ⑤ §3）。
  - ⑦ 战斗（**伤害请求协议** + 状态结算，L2）。
  - ② 角色与职业（状态模型，L0）。
- **提供接口（被依赖方）**：→ ⑬ HUD：敌人 HP/状态/Boss 血条数据。
- **上游接口需求（→程基岩）**：telegraph 前摇下限常量（按 tick 率）、同步时序（systems-index §5 ⑧）。

## 3. 核心机制（修订后，刷怪 bullet 强化引用 `SpawnPoint[]`）
- **刷怪**：基于 ⑤ 输出的 `SpawnPoint[]` 实例（`pos` / `enemy_type_id` / `wave` / `count`）生成敌人实体；**只读实例，不调用 ⑤ 生成函数**（纪律 A，详见 ⑤ §3）。
- **行为**：寻路（地牢碰撞层）、攻击选择（按距离/冷却/编队）、编队（杂兵集群、精英独立、Boss）。
- **分层**：杂兵（小多锐角集群）、精英（更大专属剪影常驻 DANGER 描边）、Boss（巨型多部件分阶段）。
- **攻击表达**：所有攻击经 **⑦ 伤害请求协议**提交（`伤害请求(source, target, amount, type, application_tick)`），不自行结算。生成 **telegraph**（静态可读形状 + 色块 + 声），前摇满足 ④/⑦ §7 不等式。
- **纪律 B 落地**：本系统只决策行为 + 发伤害请求；伤害/状态结算全在 ⑦。

## 4. 数值/平衡初稿（`待调`）
- **`TICK_RATE`：引用 `ADR-NET-01`（锁 30Hz），本系统不再单独定义（与 ① §4 / ④ §4 / ⑦ §4 一致）。**
- 杂兵 HP 30–60；精英 HP 120–200；Boss HP 800–1500（按层递增）。
- **攻击前摇（telegraph）**：杂兵 ≥0.7s、精英 ≥0.8s、Boss ≥1.0s（须满足 **预警前摇 ≥ max(P3 硬下限 0.6s, RTT 上限 250ms + 余量 K 100ms)**；已锁 `ADR-NET-01`（D3）：0.6s 硬下限主导，telegraph 下限 = 18 tick @30Hz）。
- 攻击伤害：杂兵 8–12、精英 15–20、Boss 20–35。
- Boss 阶段：2–3 阶段（按 HP 阈值切换）。
- 编队规模：杂兵 3–6 一群。

## 5. 状态机/流程
- 敌人：`SPAWN`（在 ⑤ 刷怪点）→ `ACTIVE`（行为 + telegraph）→ 受击(HP↓，由 ⑦ 结算) → `DEAD`（移除，掉落由 ⑥）/ BOSS 分阶段。
- **telegraph 时序对齐 ⑦**：预警出现 → 前摇计时 → 达**应用 tick** → ⑦ 结算伤害（与 ⑦ §7 同文）。前摇时长须满足 ④/⑦ §7 不等式。
- 断线：敌人由服务器权威，不受玩家掉线影响（本系统无掉线概念）。

## 6. 联机/权威服务器影响
- 敌人 AI 决策与 telegraph 由服务器权威（权威服务器下所有实体状态服务器裁定）。
- 攻击伤害经 ⑦ 服务器结算（producer=⑦）。
- 客户端仅表现 telegraph 与插值（由 ④ 插值）。

## 7. 可读性/UX 约束（P3 硬约束）
- 所有攻击 telegraph：**静态可读形状 + DANGER 色块 + 声**，第一帧可读，不靠细微动效（art-bible §7）。
- 前摇满足 ④/⑦ §7 不等式（已锁 `ADR-NET-01` D3）：`≥ max(P3 硬下限 0.6s, RTT 上限 250ms + 余量 K 100ms)`；0.6s 硬下限主导，telegraph 下限 = 18 tick @30Hz。
- 色盲三重编码：危险=DANGER 色 + 形状 + 图标/文字（不靠色 alone）。
- Boss telegraph 更显著（形状更大 + 声 + 阶段提示文字）。
- 敌我剪影区分（art-bible §4）：敌人锐角去饱和 + DANGER rim。
