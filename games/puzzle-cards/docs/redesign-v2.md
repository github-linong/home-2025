# 拼拼卡 · v2 重设计方案（交互 / 布局 / 功能）

> 状态：v0.2 草案（2026-08-14），已并入行业调研（`docs/design-research.md`）。待用户确认决策点后定稿。
> 背景：用户对 v1 不满意——①功能缺失（好友榜/每日任务/签到/赛季/新手引导/个人中心没有界面）；②布局视觉简陋（程序化色块 + emoji）；③交互手感与动效不足。核心玩法（拼图 + 集卡）方向不变。
> 配套：现状实况 `README.md` / `LAUNCH-CHECKLIST.md`；AI 结合 `docs/ai-integration.md`；行业调研 `docs/design-research.md`。

---

## 0. 设计目标（三条）

1. **功能对齐一期范围**：登录/用户、拼图、关卡、卡牌图鉴、新手教程、好友排行（开放数据域）、分享、助力、每日任务/签到、IAA、免费抽卡、邀请、赛季积分、个人中心——全部有界面、有入口、有状态。
2. **视觉有质感**：从「程序化色块」升级为有层次的设计系统——渐变背景、统一组件库、图标与装饰资源、系列主题化配色。
3. **交互有手感**：核心循环每一步都有反馈与仪式感——拖拽跟手、吸附弹跳、完成演出（≤2.5s）、抽卡三段式（≤3s）、新卡 lore 时刻。

**贯穿原则（来自调研）**：
- 首屏 3 秒必须能上手拼图（免注册、免教程、零弹窗 30 秒）。
- 双循环驱动：拼图产出卡面 → 图鉴点亮消耗 → 缺卡反向定位回关卡。
- 广告纪律：只在「失败结算 / 双倍奖励 / 补签 / 免费抽卡」四个有动机的断点插激励视频。
- 包体纪律：主包 < 4MB——程序化 UI + 九宫格切图，卡面/背景 WebP 远程加载，知识卡 JSON 化。

## 2. 信息架构

```
┌─────────────────────────────────────────┐
│ 顶栏：👤头像/昵称  ★赛季进度条  ⚙设置      │  ← 右上避让胶囊按钮区（88px）
│ 主场景：拼图桌（当前拼图直接可拼/今日挑战）    │
│ ───────────────────────────────         │
│ 右侧竖向功能条（3–5 个 icon，红点提示）：     │
│   🗂图鉴  📋任务  🎁抽卡  🏆排行  🎉活动     │
│ 底部：签到/离线收益浮动入口 + 安全区留白       │
└─────────────────────────────────────────┘
```

- **主场景即拼图**：首屏不设"开始"流程——桌面直接摆着当前关卡拼图（或今日挑战），拖动即玩；「下一块」引导动画指向正确位置。
- **二级页**：图鉴（集卡册）、任务、签到、赛季、抽卡、排行（开放数据域）、我的（设置/数据/帮助）——统一右侧功能条进入，全屏页 + 返回。
- **弹窗纪律**：同时只弹 1 个主弹窗，右上角固定 X；进游戏 30 秒零弹窗；插屏只在结算/失败/章节切换。

## 3. 分屏规格

### 3.1 主场景（沉浸式拼图桌）
```
┌──────────────────────────────┐
│ 👤昵称   ★★★☆☆ 赛季条    ⚙  │ ← 顶栏（避让胶囊）
│ ┌──────────────────────────┐ │
│ │                          │ │
│ │     拼图桌（当前关卡）      │ │ ← 碎片散落 + 底图淡显
│ │     未放碎片呼吸引导       │ │
│ └──────────────────────────┘ │
│        [下一块 ▶ 引导箭头]      │
│  🗂图鉴 📋任务 🎁抽卡 🏆排行 🎉活动 │ ← 右侧竖排 icon
└──────────────────────────────┘
```
- 首屏 = 关卡拼图直接可玩；完成 → 结算演出 → 自动进入下一关（无跳转感）。
- 顶栏：头像/昵称（授权后）、赛季进度条（横条 + 数字滚动）、设置。
- 右侧 icon 带红点（新卡/可领任务/签到/赛季奖励）。
- 背景：系列主题渐变 + 漂浮装饰（花瓣/星星，低性能开销）。

### 3.2 关卡（章节页签 + 线性主题地图）
```
[花语集·春] [萌宠志·萌] [食光记·味] [山河卷·远] [星辰谱·幻]
     ⭐1 ── ⭐2 ── ⭐3 ── ⭐4 ── … ── ⭐11 ── 👑12
```
- 每屏只露 3–5 关（1.5–2 倍速惯性滚动），制造「下一个」期待。
- 当前关：高亮 + 呼吸动画 + 大号「开始」；已过：按星级着色（铜/银/金）；未解锁：锁 + 剪影占位。
- 点关弹小卡：参考图缩略、难度、最佳成绩、「开始」（这里可插「看广告解锁提示」）。
- 章末 Boss 关：节点放大 + 皇冠；章节集齐 → 章末限定奖励卡横幅（收口）。

### 3.3 拼图（交互重做核心）
- **拖拽跟手**：碎片 zIndex 提升、直接跟随触摸、轻微放大 + 阴影；吸附半径内松手 → **弹簧吸附（120ms ease-out-back）**，否则轻柔回落抖动。
- **放置反馈**：正确放置 → 白闪 80ms + 弹回 + 碎片描边点亮；**拼完一行/区域 → 局部微光扩散（0.5s）**；相邻碎片成组拖动保留。
- **进度可视化**：底图随完成度渐显（20%→100%）；顶部进度 % 常驻（与图鉴进度同视觉语言）。
- **提示系统（IAA）**：看激励视频 → 高亮 1 块未放碎片（呼吸光圈 3s）/ 显示 5s 参考图 / 加时 +30s。
- **完成演出（≤2.5s，D4）**：碎片向心聚合（0.6s 光晕）→ 整图模糊到清晰点亮 → **卡面从拼图中央翻转放大飞出 → 图鉴「新卡解锁！」横幅 + 进度条增长 + lore 第一行浮现（钩子：点开看完整知识）** → 按钮：「查看知识卡」「分享给好友」「下一关」。
- 星级（≤3 星，消消乐式三星复玩）+ 用时评价。

### 3.4 抽卡（三段式演出 ≤3s，可跳过）
- **前摇（0.8–1.5s）**：卡包摇晃蓄力 + 光点汇聚 + 音效渐强。
- **揭示（0.5–1s）**：光爆 + 粒子 + 卡面翻转。
- **落地（1–1.5s）**：稀有度演出——白/蓝/紫/金四档光效 + 卡面放大特写 + 轻微震屏（传说 2.5s 全屏光幕）。
- 多连抽：逐张快翻（0.4s/张），最后最高稀有度单独重演。
- **保底进度条**：抽卡页底部「再抽 N 次必出 SR/SSR」常驻。
- **IAA**：「免费抽 × 看广告」主位亮色按钮 + 每日 2 次上限；结果页可直达图鉴对应系列。

### 3.5 图鉴（可翻页集卡册 + 常驻进度 + 缺卡获取路径）
- 页签：5 系列；顶部：总进度条（X/73，82%）+ 系列内进度；每系列一套主题底色。
- 网格 4–5 列：已收集 = 彩色卡面；未收集 = **深色剪影 + 问号**（防剧透保留）。
- **点卡翻面 0.4s**：背面剪影/花纹 → 正面卡面 + 知识卡（lore fact/tip，儿童可点读）。
- **缺卡占位点开**：三选一获取路径——「去对应拼图关卡 / 看广告免费抽 / 好友赠送」。
- 新卡：红点 + NEW 徽标 + 首次查看置顶抖动。
- **集齐一组奖励**：系列集齐 → 限定边框特效 + 章末限定拼图。
- **收集积分（闪耀暖暖式）**：收集总数 → 积分 → 兑换限定拼图/边框——长线钩子。
- 详情弹窗：大卡面弹入 + 稀有度 + lore + 「去获取」。

### 3.6 每日任务 / 签到 / 赛季（回流三件套）
- **每日首启组合**：离线收益动画（「你不在时拼图长出了 X 块碎片」爽点）→ 内嵌签到宫格 tab → 任务页。
- **签到**：7 日循环宫格，今日高亮呼吸、已领灰化打勾、未到锁 + 奖励图标；第 7 天大奖励（金色放大）；右上「补签 × 看广告」（IAA）。
- **每日任务**：3–5 条纵向列表（左侧文案 + 右侧进度条），完成打勾 → 一键领取（金币飘字）；类型：登录/拼 N 块/完成 N 局/看 N 次广告/点亮新卡。
- **赛季**：30 天横向进度条 + 里程碑图标（每级奖励）；IAA 替代通行证 = 「看广告解锁双倍赛季奖励」；末 3 天「赛季冲刺」限时任务弹窗。

### 3.7 我的 / 好友榜 / 社交
- **我的**：头像/昵称（wx 授权）、数据卡（总星/已集卡/连续签到/赛季积分）、设置（音效/隐私重新授权）、帮助 FAQ、客服。
- **好友榜**（开放数据域 sharedCanvas）：「拼图速度榜」，好友头贴 + 名次 + 「超过 TA」动机；入口：右侧排行 icon + 我的。
- **分享/助力/邀请**：分享拼好的卡面图（免费传播）；好友通过分享进入 → 双方 +1 拼图机会（云函数已有）；邀请按钮 + 被邀者新手礼包。

### 3.8 新手引导（首局即教学，D5）
- **0–10s**：进入即有一块可拼的拼图在桌面（无需「开始」）。
- **≤30s**：完成第一块拼接 → 首次成功反馈（吸附动画 + 飘字 + 音效）。
- **≤60s**：拼完首卡 → 图鉴点亮演出自动弹出（本项目第一个高潮时刻）。
- **~2min**：第一次激励视频选择项（「看广告得双倍碎片」），建立广告-奖励心智。
- **~3min**：解锁每日任务页（3 个任务，奖励可见）。
- 容错：首次失败免费提示/复活；全程可跳过；引导态存档。

## 4. 视觉系统（D2：糖果风升级）

### 4.1 组件库扩展（`Core/UI.ts` + `Core/Fx.ts`）
| 组件 | 说明 |
|---|---|
| `SideRail` | 右侧竖向功能条（icon + 红点 + 选中态） |
| `TopBar` | 顶栏（头像/资源/赛季条），避让胶囊安全区 |
| `ProgressBar` | 圆角渐变进度条 + 数字滚动（赛季/任务/保底/图鉴共用） |
| `CardFlip` | 卡面翻转 0.4s（Y 轴） |
| `Popup` | 统一弹窗（遮罩 60–70% + 入场 0.2s + 右上 X） |
| `Badge` | 红点/NEW 徽标 |
| `Particles` | 轻量粒子（星星/花瓣/光斑，单次 < 20） |
| `RarityFx` | 四档稀有度演出（白/蓝/紫/金光效 + 震屏） |
| `TweenKit` | cc.tween 封装（pop/flip/burst/float），低端机降级 |

### 4.2 视觉元素
- 背景：每屏主题渐变（`Theme.gradient`）+ 装饰层（漂浮元素）。
- 图标：emoji 升级为统一图标集（AI 生成 30+ 线性/糖果风 icon，~200KB）。
- 字体：圆润可商用字体（站酷快乐体/未来荧黑），失败回退系统字体。
- 系列主题色：5 系列各一组（主色 + 渐变 + 装饰符号），关卡/图鉴/卡面联动。

### 4.3 动效规范（统一时长）
| 动效 | 时长/曲线 |
|---|---|
| 弹窗入场 | 200ms ease-out（scale 0.9→1 + fade） |
| 吸附 | 120ms ease-out-back |
| 放置闪光 | 80ms 白闪 + 200ms 回落 |
| 行/区域完成 | 500ms 微光扩散 |
| 完成聚合演出 | 总 ≤2.5s（聚合 0.6s → 点亮 → 卡面飞出 0.5s → 横幅） |
| 抽卡三段式 | 总 ≤3s（可跳过） |
| 翻卡 | 400ms |
| 页面切换 | 150ms fade/slide（低端机关闭） |

### 4.4 弹窗与广告纪律（IAA 产品力）
- 进游戏 30 秒零弹窗零广告；插屏只在结算/失败/章节切换自然断点。
- 激励视频只在有动机处：失败重试 / 双倍奖励 / 补签 / 免费抽卡 / 提示道具。
- 所有弹窗右上 X、遮罩 60–70%、单栈不连弹；签到/任务/赛季合并进首启组合（§3.6）。

## 6. 技术实现策略（保持现有架构）

- **不动引擎/后端**：Cocos 3.8 + 云开发 + 程序化 UI 架构保留（代码构建 UI 利于快速迭代）。
- **组件先行**：`Core/UI.ts` 扩展（§4.1）+ `Core/Fx.ts`（动效）+ `Theme` 扩展（渐变/系列色/安全区常量 750×1334 基准）。
- **新屏清单**：主场景重构（HomeScreen → PuzzleDesk）、关卡地图（LevelSelectScreen 重写）、`RankScreen`（开放数据域）、`DailyTaskScreen`、`SigninScreen`、`SeasonScreen`、`ProfileScreen`、`GuideOverlay`、`SideRail`/`TopBar` 集成进 `Main.ts`。
- **数据流**：本地优先 + 云端对账（现有 Session/Cloud/Storage 模式）；任务/签到/赛季云函数已就绪，客户端补齐调用与展示。
- **包体纪律**：主包 < 4MB——图标集压缩、装饰程序化、卡面已生成走 resources 打包（后续可切远程 WebP）；装饰层节点 < 30、粒子单次 < 20。
- **安全区**：顶部 88px（状态栏 + 胶囊）避让、底部 home 条安全区留白；核心操作区居中 375×667 保障。

## 7. 分期计划（每期独立验收）

| 期 | 内容 | 验收标准 |
|---|---|---|
| **P0 视觉系统 + 导航重构** | Theme 扩展（渐变/系列色/安全区）、UI 组件库（SideRail/TopBar/Progress/Flip/Popup/Badge/粒子）、主场景拼图桌 + 侧栏、图鉴/抽卡/关卡用新组件重排、图标集 | 四屏截图对比 v1 质感明显提升；核心循环无回归 |
| **P1 拼图体验** | 拖拽手感、吸附动画、进度可视化、完成演出（≤2.5s）、lore 时刻、结果页分享 | 拖拽跟手；完成演出可录屏；E2E 通过 |
| **P2 功能补齐** | 任务/签到/赛季/离线收益、我的、好友榜（开放数据域）、分享/邀请、新手引导 | 一期范围全走通；单测 + E2E |
| **P3 AI 玩法** | 每日挑战图（A3）、个性化难度（A4） | 每日新图可拼；难度自适应生效 |
| **发布** | 提审材料、真机预览、上线 | LAUNCH-CHECKLIST 全勾 |

## 8. 参考调研（已并入）

完整报告：`docs/design-research.md`（11 款爆款参考 + 7 维 UI/UX 模式提炼 + 拼图集卡结合先例 + 平台规范 + 5 条针对性建议 + 40+ 来源）。
