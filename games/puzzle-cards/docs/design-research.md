# 「拼图 + 集卡收集」微信小游戏 — 交互与页面设计调研报告

> 目标用户：女性 + 儿童｜暖色糖果风｜纯 IAA 广告变现｜AI 生成美术与图鉴知识卡
> 调研时间：2026 年（信息以 2025–2026 优先，含经典长线案例）

---

## 0. 摘要（先说结论）

- **主页范式**：不要做宫格主页，做「单页沉浸式主场景 + 右侧竖向功能条」。首屏 3 秒必须能上手拼图。
- **双循环驱动**：拼图产出资源 → 资源解锁/点亮图鉴卡；图鉴缺卡 → 反向定位回拼图关卡（梦幻花园/肥鹅的双系统互相驱动 + 集五福的"缺卡焦虑"）。
- **收集即第二主页**：图鉴做成可翻页的"集卡册"，缺卡剪影占位 + "去收集/看广告"按钮，进度条 X/总数 常驻。
- **演出要短、可跳过**：抽卡/开箱三段式（前摇→揭示→稀有度落地）总时长 ≤3s；完成拼图点亮卡面 ≤2s。
- **广告插入纪律**：进游戏前 30 秒零弹窗；只在"失败结算、双倍奖励、补签、免费抽卡"四个有动机的节点插激励视频。
- **工程约束**：主包 4MB 下，核心 UI 走程序化绘制 + 九宫格切图复用，卡面/背景走 WebP 远程加载 + 本地缓存。

## 1. 【爆款参考】微信小游戏平台休闲/收集/合成/拼图类代表作

### 1.1 羊了个羊（三消/堆叠消除，IAA 教科书）
- **品类**：Stack 式堆叠三消 + 高难度的"伪 3D"翻层消除。
- **核心循环一句话**：第一关 30 秒教会你玩，第二关地狱难度"差一点就赢"，看广告换道具（移出/撤回/洗牌/复活）后循环挑战。
- **为什么值得参考**：
  1. **首关即完整教学**——新手引导不用单独做教程页，第一局拼图就是引导。
  2. **"差一点就赢"是看广告的最强动机**——道具按钮在失败边缘高亮跳动，直接引导激励视频。
  3. **社交榜单（省份/羊群排名）** 做裂变与留存，对应本项目好友排行榜的动机设计。
- 来源：[界面新闻：爆了的《羊了个羊》](https://m.jiemian.com/article/8084952.html)、[21世纪经济报道：复盘爆红路径](https://m.21jingji.com/article/20220919/herald/11956e060a78719583c4c13318c79916_zaker.html)、[新京报：看广告被薅羊毛？](http://www.bjnews.com.cn/detail/166324617314944.html)

### 1.2 合成大西瓜（物理合成，即开即玩）
- **品类**：物理掉落 + 两两合成（2048 × 物理）。
- **核心循环一句话**：零学习成本开局，扔水果两两合成、见缝插针，爆掉后看广告复活接着来。
- **为什么值得参考**：
  1. **免注册即开局**——微信小游戏天然如此，但提醒 UI 上"开始游戏"按钮必须是首屏唯一主 CTA。
  2. **合成瞬间的解压反馈**（弹跳物理 + 音效）——本项目拼图"拼合成功"的吸附动画同样承担爽点。
  3. 失败惩罚轻、复活入口明显——拼图"卡住时看提示/看广告得提示"沿用此模式。
- 来源：[钛媒体：一夜爆火](https://www.tmtpost.com/4958963.html)、[百度百科：合成大西瓜](https://baike.baidu.com/item/%E5%90%88%E6%88%90%E5%A4%A7%E8%A5%BF%E7%93%9C/55907746)

### 1.3 开心消消乐（三消长线，关卡页范式）
- **品类**：三消 + 大地图关卡推进 + 宠物收集。
- **核心循环一句话**：过关得星 → 星星解锁藤蔓地图新区域 → 收集动物伙伴/装扮，三星与收集双钩子留住长线玩家。
- **为什么值得参考**：
  1. **地图式关卡选择页**：一条蜿蜒主题路径（藤蔓/森林），节点即关卡，节点上显示目标与已获星级，路径尽头是新区域——探索感 + 解锁期待，是关卡页首选布局。
  2. **三星评分**制造复玩理由，可映射为拼图的"星级/拼图用时评价"。
  3. 失败可用道具（加步数）——对应拼图"加时/提示"道具位。
- 来源：[乐元素徐辉：休闲游戏制作经验](https://shouyoujz.com/archives/14042)、[设计杂志：开心消消乐游戏体验分析](http://designmag.cn/%e5%bc%80%e5%bf%83%e6%b6%88%e6%b6%88%e4%b9%90%e6%b8%b8%e6%88%8f%e4%bd%93%e9%aa%8c%e5%88%86%e6%9e%90/)

### 1.4 梦幻花园 / 梦幻家园（消除+装修，双系统互驱）
- **品类**：三消 + 家园装修建造。
- **核心循环一句话**：消除过关得星星 → 星星消耗在花园装修任务上 → 装修剧情推进 → 继续消除。
- **为什么值得参考**：
  1. **双系统互相驱动**：玩法产出资源、养成消耗资源，形成"永远有下一个目标"的循环——本项目即"拼图→解锁新卡面→图鉴进度→新拼图主题"。
  2. 每个装修小任务都是一个 5 分钟内的"完成感"节点——对应拼图按"区域/主题"拆分小目标。
- 来源：[百度百科：梦幻花园](https://baike.baidu.com/item/%E6%A2%A6%E5%B9%BB%E8%8A%B1%E5%9B%AD/1559803)

### 1.5 动物餐厅（放置经营 + 收集图鉴，长线小游戏）
- **品类**：放置经营 + 客人/信件/海报收集图鉴。
- **核心循环一句话**：挂机收钱 → 解锁新客人与设施 → 图鉴点亮与信件收集驱动每日回归。
- **为什么值得参考**：
  1. **收集图鉴是长线留存的钩子**：客人图鉴、信件图鉴、海报图鉴，本项目的"知识卡图鉴"直接对标。
  2. 4 人团队流水过亿——简笔卡通美术 + 强氛围也可成功，印证 AI 美术路线可行。
  3. 离线收益回归弹窗（"你不在时餐厅赚了 X"）是日活利器，拼图可做"离线获得提示碎片"。
- 来源：[TapTap：4人团队研发流水过亿](https://www.taptap.cn/moment/499001671934807528)、[百家号：流水过亿的背后](https://baijiahao.baidu.com/s?id=1788896057660843874)

### 1.6 猫咪和汤（放置收集 + 猫咪图鉴，治愈系）
- **品类**：放置模拟 + 猫咪收集养成。
- **核心循环一句话**：放置产出汤品 → 收养新猫 → 图鉴点亮 + 房间装扮，靠猫的"人格化"产生情感连接。
- **为什么值得参考**：

  2. 暖色治愈美术 + 软萌音效，是"女性 + 儿童"目标人群的标杆氛围。

## 2. 【UI/UX 模式提炼】

### 2.1 主页/导航模式

- **微信小游戏主流 = 单页沉浸式 + 角落/侧边入口，不是底部标签栏**。原因：小游戏没有 App 首页包袱，首屏 3 秒要进玩法；底部被安全区（home 条）挤压。功能重的长线手游才用底部标签栏。
- **推荐结构（本项目）**：
  - 主场景 = 拼图桌（当前拼图直接铺在首屏，或"选择拼图"为唯一主入口）。
  - 顶栏：左上头像/昵称 + 等级；右上金币、体力、设置（图标化）。
  - 右侧竖向功能 icon 条（3–5 个）：图鉴｜任务｜商城/抽卡｜排行榜｜活动——竖排不占横向空间，用红点/角标提示新内容。
  - 签到、赛季、限时活动用"角落浮动入口 + 角标"，不常驻。
- 参考：[优设：移动端导航设计模式](https://www.uisdc.com/mobile-navigation-design-mode)、[兰亭妙微：移动端导航设计](http://www.lanlanwork.com/blog/post-4992.html)

### 2.2 关卡选择页布局节奏

- **两种主流范式**：
  1. **线性主题地图**（开心消消乐式）：蜿蜒路径 + 节点关卡，路径尽头解锁新区域/BOSS。推荐用于"拼图主题章节"：每章一条糖果主题路径（甜点镇/花海/星空），节点上显示星级与目标。
  2. **宫格列表**（数字网格）：适合纯关卡式，信息密度高但缺少探索感。
- **节奏细节**：
  - 每屏只露 3–5 个可见关卡，制造"下一个"期待；地图可 1.5–2 倍速惯性滚动。
  - 当前关卡：高亮 + 呼吸动画（scale 1.05 循环）+ 大号"开始"按钮。
  - 已过关卡按星级着色（铜/银/金），未解锁关卡 = 锁 + 剪影占位（不用空白）。
  - 章节完成：章末特殊奖励卡（如章节限定图鉴卡），用"领取"横幅收口。
- 来源：[GameRes：游戏关卡设计方法论](https://www.gameres.com/904842.html)、[开心消消乐体验分析](http://designmag.cn/%e5%bc%80%e5%bf%83%e6%b6%88%e6%b6%88%e4%b9%90%e6%b8%b8%e6%88%8f%e4%bd%93%e9%aa%8c%e5%88%86%e6%9e%90/)

### 2.3 卡片收集/图鉴/集卡册展示范式

- **网格展示**：宫格 4–6 列，已收集 = 彩色卡面，未收集 = **深色剪影 + 问号**；图鉴顶部常驻进度条（"已收集 X/120，82%"）+ 按主题分组 + 分组内小进度。
- **交互细节**：
  - 点卡翻面动画（0.3–0.5s）：背面是剪影/花纹，正面是卡面 + 知识卡信息（本项目差异化：卡面 + 图文冷知识 + 语音可点读，儿童友好）。
  - 新获得卡：红点 + 置顶抖动提示；首次查看有"NEW"徽标。
  - 缺卡占位点开：弹出"获取途径"——去对应拼图关卡 / 看广告免费抽 / 好友赠送（三选一按钮）。
  - 稀有度边框颜色层级（明确四档）：普通白 → 稀有蓝 → 史诗紫 → 传说金；图鉴网格用底色区分稀有度区域。
  - 集齐一组（如一套"四季"4 张）触发组奖励：称号/特效边框/限定拼图。
- 参考专利（图鉴展示封面/名称/进度）：[CN115888075A](https://patents.google.com/patent/CN115888075A)

### 2.4 抽卡/开箱仪式感设计

- **三段式演出**（总时长 ≤3s，可点击跳过）：
  1. **前摇**（0.8–1.5s）：宝箱/卡包摇晃蓄力 + 光点汇聚 + 音效渐强。
  2. **揭示**（0.5–1s）：卡面翻转 / 光爆 + 粒子。
  3. **落地**（1–1.5s）：稀有度演出——普通白光 → 稀有蓝光 → 史诗紫光 → 传说金光 + 卡面放大特写 + 卡名播报 + 轻微震屏（传说可到 2.5s，带全屏光幕）。
- **多连抽**：先逐张快翻（每张 0.4s），最后把最高稀有度那张单独放大重演。
- **保底机制可视化**：抽卡页底部"再抽 N 次必出传说"进度条（IAA 下这是留存与广告频次的挂钩点）。
- **IAA 结合**："免费抽卡 × 看广告"按钮常驻抽卡页主位，亮色高亮 + 倒计时。
- 来源：[小红书：游戏商业化·付费形式与设计](https://www.xiaohongshu.com/discovery/item/641713c8000000001300db80)

### 2.5 弹窗层级与打断策略

- **层级栈管理**：同时只弹 1 个主弹窗；新弹窗压栈、关闭回退；主玩法场景内禁止无来源弹窗。
- **打断纪律（IAA 核心）**：
  - 进游戏前 30 秒零弹窗、零广告（首屏干净，先给操作爽感）。
  - 插屏广告只出现在**结算/失败/章节切换**等自然断点。
  - 激励视频只出现在玩家有动机处：失败重试、双倍奖励、补签、免费抽卡。
  - 签到/离线收益弹窗：先展示"离线收益 +X"的爽点动画，再叠加任务/活动入口（弹窗内做二级 tab，避免连弹）。
- **通用规范**：所有弹窗有关闭按钮且位置固定（右上角 X）；遮罩 60–70% 黑色；弹窗入场 0.2–0.3s 缩放 + 淡入，退场 0.15s。
- 来源：[TTAF 213-2024 移动应用软件信息窗口弹出行为规范（PDF）](http://www.taf.org.cn/upload/AssociationStandard/TTAF%20213%E2%80%942024%20%E7%A7%BB%E5%8A%A8%E5%BA%94%E7%94%A8%E8%BD%AF%E4%BB%B6%E4%BF%A1%E6%81%AF%E7%AA%97%E5%8F%A3%E5%BC%B9%E5%87%BA%E8%A1%8C%E4%B8%BA%E8%A7%84%E8%8C%83.pdf)、[兰亭妙微：APP UI 弹窗设计全解](http://www.lanlanwork.com/blog/post-14506.html)、[华信智原：弹窗设计规范](https://www.hxsd.com/information/12983/)、[长线运营游戏客户端 UI 架构：活动越多越要克制](https://plumephp.com/client-ui-architecture-for-live-games/)

### 2.6 新手引导范式（前 3 分钟）

- **范式：首局即教学，"做了就会"代替"说了才懂"**（羊了个羊第一关、合成大西瓜零教学）。无强制教程弹窗，用高亮 + 箭头每步只讲一件事。
- **前 3 分钟节奏模板（本项目）**：
  - 0–10s：进入即有一块可拼的拼图在桌面上（不需要"开始"流程）。
  - ≤30s：完成第一块拼接，弹出首次成功反馈（拼合吸附动画 + 金币飘字 + 音效）。
  - ≤60s：引导第一次图鉴点亮——拼完第一张卡，图鉴页自动弹出"收集成功"演出（这是本项目的第一个高潮时刻）。
  - ~2min：第一次激励视频——给"看广告得双倍金币/稀有碎片"的选择项，让玩家学会广告-奖励心智。
  - ~3min：解锁每日任务页（3 个任务，奖励可见）。
- **容错**：首次失败免费复活/免费提示（建立"失败可重来、广告可帮忙"预期）。
- 来源：[GameRes：以构建乐趣为目标的新手引导设计](https://www.gameres.com/867245.html)、[腾讯云：如何将新手引导模块化](https://cloud.tencent.com.cn/developer/article/1831757)、[网易学院：游戏的前十五分钟·情境学习](https://api.academy.163.com/course/careerArticle?course=113)、[微信公众号：前5分钟都留不住玩家，教程差在哪](https://mp.weixin.qq.com/s/qsd4iw4nNc-BssoG2tDiFQ)

### 2.7 每日任务/签到/赛季 UI 范式

- **签到**：**7 日循环宫格**（7 格横排），今日格高亮 + 呼吸动画；已领 = 灰化打勾；未到日期 = 奖励图标 + 锁；**第 7 天大奖励**（传说卡/抽卡券）用金色 + 放大突出。右上角"补签"（看广告补签 1 次，IAA 标配）。签到页与"离线收益"合并成每日首启弹窗。
- **每日任务**：3–5 条纵向列表，左侧任务文案 + 右侧进度条（如"拼 3 局 2/3"）；完成打勾 → 一键领取（金币飘字 + 音效）。任务类型：登录、拼 N 块、完成 N 局、看 N 次广告、点亮 N 张新卡。
- **赛季**：时长 2–4 周，横向进度条 + 里程碑节点图标（每级一个奖励）；IAA 无付费线，用"广告解锁双倍赛季奖励"替代付费通行证；赛季首日与末 3 天给弹窗提醒（末 3 天"赛季冲刺"限时任务）。
- 来源：[优设：签到组件的设计方式详解](https://www.uisdc.com/check-in-component)、[GameRes：从游戏登录签到界面看留存设计](https://www.gameres.com/877793.html)、[CSDN：全程用AI做商业级手游·EP6 留存系统](https://blog.csdn.net/m0_62670368/article/details/161806662)

## 3. 【拼图 + 集卡的结合先例】

### 3.1 拼图过程与完成时刻的演出

- **过程中（进度反馈）**：实时完成百分比 + 剩余块数常驻（图鉴进度条同款视觉语言）；拼完一行/一个区域 → 局部微光扩散演出（0.5s）；碎片吸附动画 0.3–0.5s（吸附瞬间音效 + 轻微震屏 + 粒子）。
- **完成时刻（高潮演出，≤2.5s）**：整图从模糊到清晰点亮 → 金色光晕展开 → 画框特效 → **卡面获得动画**：拼好的图直接变成图鉴卡，卡面从拼图中央翻转放大飞出 → 图鉴"新卡解锁！"横幅 + 进度条增长动画 + 知识卡第一行文字浮现（钩子：点开看完整知识）→ 底部两个按钮："查看知识卡" + "分享给好友"（分享拼好的图 = 免费传播 + 好友助力缺口）。
- 拼图计时/星级评价（≤3 星）可复用开心消消乐三星复玩逻辑；拼图"提示"道具 = 看广告点亮一块。

### 3.2 集卡与拼图互相驱动（业界做法）

| 驱动方向 | 机制 | 业界先例 |
|---|---|---|
| 玩法 → 收集 | 完成拼图 → 点亮卡面 → 图鉴进度 | 梦幻花园（消除产星→装修）、动物餐厅（收集图鉴） |
| 收集 → 玩法 | 图鉴缺卡 → 点开"去收集" → 直达对应拼图主题关卡 | 集五福（缺卡焦虑 + 明确获取途径） |
| 收集 → 重复游玩 | 图鉴收集总数 → 积分 → 兑换限定拼图/特效边框 | 闪耀暖暖图鉴积分系统 |
| 收集 → 社交 | 重复卡 → 赠好友 / 好友助力拼图块 | 集五福赠卡换卡、旅行青蛙晒明信片 |
| 收集 → 长线内容 | 知识卡（AI 生成图文/可点读）→ 收藏册翻页浏览，儿童用户可反复观看 | 旅行青蛙明信片册、猫咪和汤猫咪图鉴 |

- **推荐组合**：拼图完成 = 获得卡面（强反馈闭环）；章节集齐 = 解锁章节限定拼图；每日任务奖励"稀有卡碎片"，碎片攒齐可合成任意缺卡——给"缺哪张"一个可执行的补全路径。

## 4. 【微信小游戏平台规范】

### 4.1 设计分辨率与安全区

- **设计稿基准**：750 × 1334（竖屏，iPhone 6/7/8 比例），引擎层用 Fit 缩放适配，背景用可延展/模糊渐变填充不同长宽比（19.5:9、16:9、iPad）。
- **顶部安全区**：微信小游戏右上角**胶囊按钮（约 78–88px 高，横跨右侧）**必须避让——顶栏标题/资源不上探到胶囊区域；iPhone 刘海屏额外留顶部状态栏（44–47pt）。
- **底部安全区**：home 指示条区域（约 34–68px）不放交互主按钮；底部锚点内容 + safe-area-inset-bottom 偏移。
- **关键 UI 居中区**：核心可操作内容（拼图棋盘、主按钮）放在 375 × 667 中心区域，边缘只放装饰。

### 4.2 包体限制下的 UI 资源策略

- **限制**：主包 **4MB**；总包（主包 + 分包）约 **20MB**，单个分包 4MB（可做"拼图主题包"远程分包按需下载）。微信小游戏后台对主包超限直接拒绝上传。
- **UI 资源策略（本项目适用）**：
  1. **程序化绘制 UI 优先**：弹窗底、按钮、进度条、边框用代码绘制 + 九宫格切图（1 张 9-patch 撑起所有弹窗），不逐弹窗出图——省包体且可统一主题色（糖果粉/奶油黄/薄荷绿层级）。
  2. **卡面/背景走远程资源**：WebP/JPG 压缩后 CDN 分发 + 本地缓存；图鉴知识卡文字走 JSON 数据（AI 生成内容天然是数据，不进包）。
  3. 动效用引擎序列帧/骨骼/粒子，不用大体积视频；音频 mp3 低码率（64kbps 以下）。
  4. 主题内容（新拼图包）走分包或远程加载，主包只含首章。

### 4.3 竖屏适配要点

- 以 750×1334 为设计稿，四角锚点定位；重要内容居中有保障区域；顶部预留 88px（状态栏+胶囊）、底部预留安全区；iPhone 刘海屏用 safe-area 常量；转屏锁竖屏。

- 来源：[微信小游戏设计指南（官方）](https://developers.weixin.qq.com/minigame/en/design/)、[微信小游戏屏幕适配（Unity 移植文档）](https://developers.weixin.qq.com/minigame/dev/guide/game-engine/unity-webgl-transform/Design/fixScreen.html)、[Cocos Creator 小游戏上线前检查清单：性能、包体、适配、审核](https://eastondev.com/blog/zh/posts/dev/20260522-cocos-mini-game-launch-checklist/)、[阿里云：微信小游戏使用小结](https://developer.aliyun.com/article/1376705)、[CSDN：Cocos 微信小游戏包体优化实战](https://blog.csdn.net/weixin_29247219/article/details/158060039)

## 5. 【针对性建议】5 条具体改进（含理由）

**① 主页改为「单页沉浸式拼图桌 + 右侧竖向功能条」，删除宫格主页**
理由：微信小游戏首屏 3 秒决定留存，宫格主页多一次跳转；参考合成大西瓜即开即玩。实现：首屏 = 当前拼图 + 底部"下一块"引导，右侧 3–5 个功能 icon（图鉴/任务/商城/排行），顶栏左头像右资源，全部红点化提示。

**② 图鉴做成「可翻页集卡册 + 常驻进度」，缺卡给明确获取路径**
理由：收集是第二核心，图鉴进度条（X/总数）是留存仪表盘；缺卡剪影 + "去收集/看广告/好友赠送"三选一按钮复刻集五福的缺卡焦虑。实现：宫格 5 列 → 点卡翻面 0.4s → 正面卡面 + 知识卡（可点读，儿童向）；新卡置顶 + NEW 徽标；集齐一组解锁限定边框与特效。

**③ 抽卡/开箱三段式演出（≤3s、可跳过）+ 保底进度条 + 广告换抽**
理由：仪式感决定卡的价值感，但反复观看必须能跳过；保底可视化把"还差 N 次"变成下次登录动机。实现：前摇 1s → 揭示 0.8s → 稀有度落地 1.5s（金/紫/蓝/白四档颜色层级），"免费抽 × 看广告"主按钮 + 保底条。

**④ 新手引导「首局即教学」：30s 第一块、60s 第一次点亮、2min 第一次广告**
理由：引导目标是让玩家 3 分钟内学会"拼图→得卡→看广告得更多"的完整心智闭环，而非教操作。实现：首屏即拼图、首块吸附动画即教学；拼完首卡自动弹出图鉴点亮演出；首个双倍奖励广告在第 2 分钟出现；首次失败免费复活。

**⑤ 弹窗纪律 + 每日回流组合拳（离线收益 → 7 日签到 → 每日任务 → 赛季）**
理由：IAA 游戏广告体验即产品力，弹窗必须守"30 秒零弹窗、断点才插、可关闭"；签到/任务/赛季是日活三件套。实现：首启 = 离线收益动画（+N）→ 内嵌签到宫格 tab → 每日任务页；补签与双倍任务奖励用激励视频；赛季 4 周横向进度条 + 末 3 天冲刺弹窗。

**附：包体纪律**（建议并列为工程红线）：主包 4MB 内——弹窗/按钮/进度条程序化 + 九宫格，卡面/背景 WebP 远程加载，知识卡内容 JSON 化，主题包走分包/远程。
