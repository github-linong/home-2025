## 重启一条规则

重启前先想清楚：**这次改了什么、之前的死磕点这次打算怎么绕**。

每个项目暂停时都列出过「为什么暂停」「当时解决不了的问题」，重启时这部分必须被回答，否则大概率重蹈覆辙。

## 暂停 vs 下线 区别

- **暂停**：仓库内代码、文档、设计稿保留；可能保留 systemd 服务 / 数据库；恢复成本低（小时级）
- **下线**：源码 / 部署 / 服务全部拆除（除非这里明确标了保留）；重启需要从设计稿重新写代码
